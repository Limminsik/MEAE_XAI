## 2. 잡음 주입

- NSTDB `bw`/`ma`/`em`의 **채널 0(noise1)** 사용. NSTDB 잡음은 2채널 기록기로 녹음돼
  noise1/noise2 두 유도를 가지며, `nst` 도구가 채널 번호끼리 짝지어 섞는 관례에 따라
  MLII가 놓인 0번 채널의 짝인 noise1을 쓴다.
- 세 잡음을 **항상 모두** 주입하고 강도만 무작위. SNR은 잡음별 독립 균등추첨 **[0, 12] dB**.
- 신호 전력은 **분산 기준**(`x_clean.var()`), 잡음 전력은 `mean(n**2)`.
  → 실측 SNR과 추첨 SNR의 **최대 오차 2.92e-07 dB** (DoD 기준 ±0.1 dB).

### 왜 분산 기준인가 (설계 §4-4 수정 사유)
MIT-BIH 원신호에는 전극 오프셋이 남아 있어 분절 평균이 0이 아니다 (중앙 −0.219 mV,
|DC| 95%분위 0.895 mV). 신호 전력을 `mean(x**2)`로 잡으면 이 DC가 전력의
**중앙 35.1%, 최대 97.5%** 를 차지해, 명목 SNR과 실제 SNR이 분절마다 0–10 dB 어긋난다.
분산 기준으로 바꾸면 이 오차가 사라지고, ECG 잡음제거 문헌의 SNR 정의(§8의 SNR 개선)와도 일치한다.
잡음 쪽은 `mean(n**2)`를 유지한다 — 기저선 오프셋은 오차가 아니라 제거 대상 잡음의 일부이기 때문이다.

## 3. 진폭 조절의 타당성 검증

주입 배율 `a`와 그 결과 잡음 진폭이 실제 녹음된 잡음의 범위 안에 있는지 확인한 것.

| 잡음 | NSTDB 원본 RMS | 주입 후 RMS 중앙 [5–95%] | 배율 중앙 [5–95%] | 배율 > 1 비율 |
|---|---|---|---|---|
| bw | 0.466 mV | 0.163 [0.060 – 0.428] | 0.550 [0.133 – 2.021] | 22.6% |
| ma | 0.193 mV | 0.158 [0.062 – 0.426] | 0.958 [0.308 – 3.512] | 47.3% |
| em | 0.730 mV | 0.163 [0.061 – 0.413] | 0.232 [0.082 – 0.696] | 1.4% |

**해석**
- 세 잡음 모두 주입 후 RMS 중앙값이 **원본 RMS 이하**이고, 세 잡음의 주입 후 진폭이
  0.16 mV 부근으로 수렴한다 (SNR을 같은 범위로 맞췄으므로 당연한 결과이자 정합성 확인).
- 배율이 1을 넘는(=원본보다 증폭되는) 비율은 잡음마다 다르다. em은 원본 진폭이 가장 커서
  거의 항상 감쇠(1.4%)하지만, **ma는 47.3%에서 증폭**되고 95%분위가 3.5배에 이른다.
  ma 원본 RMS가 0.193 mV로 작아 낮은 SNR을 맞추려면 키워야 하기 때문이다.
  3.5배여도 절대 진폭은 0.68 mV로 실제 근전도 잡음 범위 안이다.
- **진폭 조절이 필요한 이유**: 기록 간 심전도 전력이 26배(0.050–1.318 mV²) 차이 난다.
  조절 없이 같은 잡음을 더하면 진폭이 큰 환자는 SNR 14 dB, 작은 환자는 0 dB가 되어
  설계한 [0, 12] dB 범위가 무의미해진다. 진폭 조절은 SNR을 통제 변수로 만드는 장치다.

## 4. 잡음 원본 재사용률

학습용 잡음 풀은 21.1분(451,401개 시작점)인데 train 분절 5,760개 각각에 잡음 3종을 주입하므로
잡음마다 5,760개 창을 뽑는다.

창이 겹치지만 매번 정렬 위치·주입 배율·상대 심전도가 달라 실질 다양성은 확보된다.
평가용 풀(9.0분, 191,401개 시작점)에서는 val·test 2,520 분절이 뽑히므로 1샘플당 평균 47.4회다.

## 5. 한계 (§10 고찰용)

1. **분절 단위 진폭 정규화의 비현실성** — 실제 잡음 세기는 전극·움직임으로 정해지지
   환자의 심전도 진폭에 맞춰 조절되지 않는다. 분절마다 SNR을 통제하기 위해 감수한 인공성이다.
   기록 단위 주입이 이 점에서는 더 현실적이나, 학습용 잡음 풀(21.1분)이 기록 길이(30.1분)보다
   짧아 이어붙이기 없이는 불가능하고, SNR 가짓수가 46개로 줄어 통제 변수로 쓸 수 없다.
2. **참조 신호의 미량 오염** — `x_clean`으로 쓰는 MIT-BIH 원신호 자체에 실제 잡음이 들어 있다.
   `~`(신호품질 변화) 주석 기준 MLII가 잡음으로 표시된 구간은 전체의 **1.68%**(23.2분,
   10초 분절 환산 최대 139개)다. S4의 clean 참조와 S5의 채점 기준이 이만큼 오염돼 있다.
3. **SNR 정의가 NSTDB `nst` 도구와 다르다** — `nst`는 신호 전력 S를 QRS 첨두간 진폭
   (정상 QRS 300개의 상하위 5% 절사평균)의 제곱/8로 정의한다. 우리는 분절 분산을 쓴다.
   따라서 같은 "SNR 6 dB"라도 두 정의의 잡음 세기가 다르다. 원고에 명시할 것.
4. **평가셋의 부정맥 비율이 낮다** — 층화 없는 무작위 분할의 결과로 부정맥 비율 중앙값이
   train 0.085, val 0.031, test 0.003이다. 극단적 사례(107 100%, 217 89%, 232 78%)가
   모두 train에 있다. S5의 R-피크 F1을 해석할 때 평가셋이 상대적으로 수월한 구성임을 밝힐 것.

## 8. sparse mixing 손실 — 두 구현의 차이와 우리의 선택

`models/separation_loss.py`에는 두 클래스가 있고 **두 논문이 서로 다른 쪽을 쓴다.**

| | `WeightSeparationLossAlternative` | `WeightSeparationLoss` |
|---|---|---|
| 사용 논문 | **Neurocomputing 2025 (ECG, `mesa_ecg_bss`)** | Comput Biol Med 2025 (PPG) |
| 벌점 대상 | 대각 밖 **띠(strip)** | 비대각 **블록** 전부 |
| 항의 개수 | 2(K−1) — K=8이면 14개 | K²−K — K=8이면 56개 |
| 계산 단위 | 띠 하나를 통째로 평균 | 블록마다 각각 평균 |
| 가중치 `sep_lr` | **1e-3** | 0.05 |
| 함께 쓰인 `zero_lr` | 1e-2 | 1e-1 |
| `hidden` | 64 | 256 |

**차이의 성격**: `Alternative`는 `i`번째 행 블록의 오른쪽 전부와 `i+1`번째 행 블록의 왼쪽
전부를 각각 하나의 띠로 묶어 평균한다. 띠들이 서로 겹치므로 **대각에서 멀리 떨어진 블록일수록
여러 띠에 중복 포함되어 더 강하게 억제**된다. 반면 `WeightSeparationLoss`는 모든 비대각
블록을 동등하게 벌점한다.

**우리의 선택: `Alternative` + `sep_lr = 1e-3`** (`configs/default.yaml: loss.sep_impl: alternative`)

선택 근거
1. 우리 대상은 ECG이고, 선행이 ECG 실험(`mesa_ecg_bss`)에 쓴 구현이 `Alternative`다.
   설계 §5A도 `mesa_ecg_bss`를 출발점으로 지정했다.
2. 가중치는 구현과 짝을 이룬다. PPG 쪽 값(0.05)은 항의 개수와 계산 단위가 다른
   `WeightSeparationLoss`에 맞춰 조정된 값이라 그대로 옮기면 스케일이 어긋난다.
3. 분리가 부족하면 설계 §6의 붕괴 규칙(인코더 쌍 |corr| > 0.7이 5에폭 지속)에 따라
   `lambda_mixing`을 상향 검토한다. 구현을 바꾸는 것이 아니라 가중치를 조정한다.

두 구현 모두 `SEP_IMPLS` 사전에 등록해 두었으므로(`alternative` / `blockwise`),
필요하면 config 한 줄로 교체해 민감도 분석을 할 수 있다.

## 9. 입력 길이와 패딩 (T3 실측)

선행 `EncoderBlock` 8개가 각각 `MaxPool1d(2, 2)`를 가진다 → **다운샘플 배수 256 (= 2⁸)**.
설계 §5A는 "깊이 4"를 가정했으나 실제 깊이는 8이다. 실측 결과:

| 입력 길이 | 출력 길이 | 인코딩 길이 | 판정 |
|---|---|---|---|
| 3600 | 3584 | 14 | **불일치** (14×256 = 3584) |
| **3840** | 3840 | 15 | OK (= 256×15) |
| 4096 | 4096 | 16 | OK (= 256×16) |
| 12288 (선행 MESA) | 12288 | 48 | OK |

**필요 조건은 2의 거듭제곱이 아니라 256의 배수다.** 후속 저장소가 근거를 직접 남겨놨다:

```yaml
signal_duration: 48   # 48s (6000 samples) + 144 padding is divisible by 2^8
padding: 144          # 6000 -> 6144 = 256 x 24
```

선행도 2의 거듭제곱(8192)이 아니라 **256의 다음 배수**를 골랐다. 같은 규칙을 적용해
**3600 → 3840 (양쪽 120샘플 대칭 제로 패딩)** 으로 확정했다. 4096을 쓰면 패딩이 496샘플로
두 배가 되어 경계 왜곡 구간과 낭비 연산이 늘어난다.

구현 규칙 (`src/model/meae.py`)
- `pad(x, 120)` / `crop(x, 120)`. 선행도 `F.pad(x, (p/2, p/2), value=0)`으로 대칭 패딩하고
  그림에서 `clip = padding/2`로 양끝을 잘라낸다.
- **모든 상관·지표는 `crop()` 후 중앙 3600 구간에서만 계산한다.** 0 구간이 상관을 희석한다.
- R-피크 인덱스는 크롭 좌표(0–3599) 기준을 유지한다.
- T5 파일럿 성분 그림에서 **경계 120샘플**의 아티팩트를 확인 항목에 포함한다.

## 10. 인코더 수 K — 6은 실행 불가

선행 디코더는 `GroupNorm(num_groups=K, num_channels=c)`를 쓴다. 채널이 32/64/128/256이라
K=6에서 `ValueError: num_channels must be divisible by num_groups`로 실패한다.
인코더 채널 `c // K`도 절사되어 총 채널이 설계값과 어긋난다 (32 → 5×6 = 30).

```
K=2: OK  인코딩 (32, 15)  파라미터 2.02M
K=4: OK  인코딩 (16, 15)  파라미터 1.48M
K=6: ★실패
K=8: OK  인코딩  (8, 15)  파라미터 1.21M
```

**설계 §3의 `n_encoders`를 [4, 6, 8] → [4, 8]로 수정.** 총 학습 2 × 3시드 = 6회.
채널을 6의 배수로 바꾸는 것은 §0 원칙 2(구조 차용) 위반이라 선택하지 않았다.
인코더당 채널은 `c // K`로 분배되어 **총 용량이 K와 무관하게 일정**하므로 K 비교는 공정하다.

## 11. 손실 가중치 — 선행 실제 값

| config 키 | 값 | 선행 출처 |
|---|---|---|
| `lambda_mixing` | 1e-3 | `mesa_ecg_bss.yaml: sep_lr` |
| `lambda_zero_recon` | 1e-2 | `mesa_ecg_bss.yaml: zero_lr` |
| `lambda_z_l2` | 1e-2 | `experiments/mesa_bss.py`에 하드코딩 |
| `weight_decay` | 1e-6, `lr_step_size` 50 (γ 0.1), `gradient_clip_val` 0.5 | 〃 |

**BCE → MSE 교체 지점**: `experiments/mesa_bss.py`의 `self.loss = nn.BCEWithLogitsLoss()`.
`zero_recon_loss`가 같은 `self.loss`를 재사용하므로 함께 MSE가 된다(설계 §5 요구사항 충족).
부수 작업 둘 — 출력의 `torch.sigmoid` 제거, 입력 min-max 정규화(`_local_normalize`) 제거.
선행은 BCE 때문에 신호를 [0,1]로 눌렀으나 우리는 mV 원값을 쓴다.

**학습 설정은 선행을 따르지 않는 지점이 있다**: 선행은 `max_epochs: 25`,
`monitor: recon_loss/train`이지만 우리는 설계 §6대로 `max_epoch: 100` + 조기종료(검증
재구성, patience 10), 체크포인트는 **검증 분리 품질** 기준이다. 선행이 README에서
"수동으로 최선의 체크포인트를 찾으라"고 권고한 작업을 정답 잡음으로 자동화한 것이며,
이 대비를 원고 방법·고찰에 명시한다.

# T4 — 지표 (S5 재정의 반영)

## 13. R-피크 F1의 실질 상한과 개선 여지 (★해석 주의)

설계 §11은 "clean vs clean → F1 1.0"을 요구하지만 **실제로는 성립하지 않는다.**
F1은 `neurokit2` 검출 결과와 **MIT-BIH 사람 주석**을 비교하는 값이라, 잡음이 전혀 없어도
검출기와 주석이 완전히 일치하지 않는다. `rpeak_prf(주석, 주석)` = 1.0은 성립하며
(단위 테스트로 고정), `score(clean, clean, 주석)`의 F1은 상한이 1.0보다 낮다.

test 300분절 실측 (허용오차 150 ms):

| 채점 대상 | F1 평균 | F1 중앙 | Precision 평균 | Recall 평균 |
|---|---|---|---|---|
| **clean** (상한) | **0.981** | 1.000 | 0.999 | 0.964 |
| **x_noisy** (마스킹 전) | **0.956** | 0.960 | 0.960 | 0.956 |

- clean에서 F1이 정확히 1.0인 분절은 55.3%뿐이고 5%분위는 0.941이다.
  누락은 대부분 **recall** 쪽이며, 분절 경계에서 잘린 박동이 주 원인으로 보인다.
- **개선 여지가 0.956 → 0.981, 즉 2.5%p뿐이다.** SNR 0–12 dB에서는 잡음이 R-피크 자체를
  거의 파괴하지 않기 때문이다.

**지표 위계 (확정)** — 4개 모두 산출하되 역할을 구분한다.

| 지표 | 역할 |
|---|---|
| **SNR 개선** | **주 지표** |
| RMSE | 교차 확인 |
| R-피크 F1 | **심박 훼손 경고등.** 개선 증명 불가. 원고엔 각주 + 상한 0.981 병기 |
| SDNN 오차 | **판정 보류** — T5 파일럿 데이터로 상한·분산 실측 후 채택/제거 |

**S5의 핵심 증거는 지표 수치가 아니라 아블레이션의 방향성 비대칭이다.**

**S5 해석 지침**
1. F1은 마스킹 효과를 재는 **민감도가 낮은 지표**다. 주 근거는 SNR 개선과 RMSE가 되고,
   F1과 SDNN은 "심박 정보를 훼손하지 않았다"는 **안전성 근거**로 쓰는 것이 정확하다.
2. 원고에는 F1의 상한 0.981을 함께 제시한다. 상한을 밝히지 않고 "F1 0.97 달성"이라고 쓰면
   실제보다 좋아 보이거나, 반대로 1.0에 못 미친다고 과소평가된다.
3. 아블레이션에서 **신호 인코더를 껐을 때의 F1 하락**은 여지가 넓으므로(위쪽으로 2.5%p,
   아래쪽으로는 0까지) 여전히 민감하게 작동한다. 주 실험의 방향성 검증에는 충분하다.

## 14. 비교군 삭제 (설계 변경)

S5를 "비교군 성능 평가"에서 **"마스킹 전후 평가 = 판별의 인과 검증"** 으로 재정의하면서
대역통과·웨이블릿·DAE 비교군을 전부 삭제했다. `src/baselines.py`는 구현하지 않는다.

주장의 구조가 근거다.
> ① 분해된다 → ② **판별된다**(S4, 핵심) → ③ **판별이 진짜다**(S5)

③은 "제안 기법이 기존 기법보다 잡음을 잘 없앤다"가 아니라 "S4가 특정한 인코더가 실제로
그 잡음을 담고 있었다"는 인과 주장이다. 이를 검증하는 대조는 외부 기법이 아니라
**같은 모델에서 마스킹만 바꾼 조건**이다. 비교군을 두면 표의 초점이 성능 경쟁으로 옮겨가
③의 논리가 묻힌다.

부수 효과: DAE 지도학습 3회가 사라져 파일럿(T5)까지의 경로가 짧아진다.

**인코더 단독 마스킹 아블레이션이 S5의 주 실험으로 승격**됐다. 판정 범주별 기대 방향은
잡음 인코더 → 개선, 신호 인코더 → 악화, 혼재·비활성 → 변화 미미이며,
이 방향성이 S4 판별의 **개입(intervention) 근거**가 된다 (S4의 상관은 연관 근거).

## 15. 지표 정의

`src/metrics.py`. 전부 clean 참조 기준이며, 마스킹 전(`x_noisy`)과 후(복원)에 **같은 함수**를
적용한다. 입력은 반드시 크롭된 3600 샘플이어야 하고, 3840이 들어오면 `ValueError`로 막는다.

| 함수 | 정의 |
|---|---|
| `snr_db(clean, est)` | `10log10(var(clean) / mean((est−clean)²))` — §4-4 주입과 동일 정의 |
| `rmse(clean, est)` | 잔차 RMS |
| `rpeak_prf(det, ref)` | 150 ms 허용오차, **1:1 배타 매칭**(가까운 쌍부터 탐욕적) |
| `sdnn_ms(peaks)` | RR 표준편차(ddof=1). RR 2개 미만이면 NaN |
| `score()` | 신호 하나 채점 (단일 진입점) |
| `score_pair()` | 전/후를 한 번에 채점하고 개선량 산출 |

10초 창의 RR은 8–19개라 SDNN 분절별 값이 불안정하다 → **중앙값[IQR]로 보고** (§8).
SDNN은 est에서 검출한 피크 vs **MIT-BIH 주석 피크**로 비교한다.

# T5 파일럿 — 지표 수정과 판정 기준 선등록

## 16. 체크포인트 선택 지표의 결함과 교체

**초판 정의**(설계 §6): `분리 품질 = 잡음별 max_k |r| 의 평균`

**결함**: 덜 학습된 모델을 최고로 뽑는다. 성분이 전부 완만한 저주파 곡선인 단계에서는
모든 성분이 bw·ma와 폭넓게 상관되어 이 값이 오히려 커진다. 파일럿 K8_seed42 실측:

| 에폭 | 검증 재구성 | 초판 분리 품질 | bw/ma/em 최고 인코더 | clean 최대 \|r\| |
|---|---|---|---|---|
| **5** | 0.1125 | **0.432 (최고)** | **(2, 2, 2) — 전부 같은 인코더** | 0.120 |
| 30 | 0.0430 | 0.371 | (2, 2, 5) | 0.419 |
| 63 | 0.0318 | 0.342 | (2, 2, 5) | 0.435 |

에폭 5 모델은 재구성에 R-피크가 전혀 없고(`figures/pilot/components.png`) 네 참조 모두
같은 인코더가 1위인 붕괴 상태인데, 초판 지표는 이것을 "최고"로 저장했다.
이 지표는 분리가 아니라 **"성분이 잡음스러운 정도"** 를 재고 있었다.

**수정 정의 (확정)**

```
분리 품질 = mean_{t∈{bw,ma,em}} max_k |r(x̂_k, t)|  −  penalty × (3 − |서로 다른 최고 인코더 수|)
penalty = 0.15   (configs/default.yaml: train.separation_duplicate_penalty)
```

- 중복 수와 최고 인코더 조합(`tops`), 앞항(`sep_base`), `clean_max_corr`를 **매 에폭 함께 기록**한다.
- **헝가리안 1:1 강제 배정은 채택하지 않았다.** 참조 4개를 서로 다른 인코더에 강제로
  배정하면 잡음이 실제로 분리되지 않았을 때도 그럴듯한 점수가 나와 **분리 실패를 가린다.**
  중복 페널티 방식은 실패를 점수에 그대로 드러낸다.
- penalty 0.15는 **0.05–0.30 전 구간에서 동일한 에폭(21)을 선택**함을 소급 확인한 값이다.
  63에폭 중 55에폭이 중복 1이므로, 페널티는 사실상 중복 2인 붕괴 에폭 8개만 걸러낸다.
  즉 결과가 페널티 값에 둔감하다.

## 17. sparse mixing 항이 최적화되지 않는다 (λ 스윕 근거)

파일럿 K8_seed42 (λ = 1e-3, 63에폭 조기종료):

| 항 | 에폭 1 | 에폭 63 | 감소율 |
|---|---|---|---|
| 재구성 (MSE) | 0.3539 | 0.0297 | 91.6% |
| **sparse mixing (원값)** | 3.580 | 3.282 | **8.3%** |
| zero reconstruction | 0.0660 | 0.0003 | 99.5% |
| 인코딩 L2 | 1.450 | 0.188 | 87.1% |

`λ×mixing / recon` 비율은 1.0% → 11.1%로 올랐지만, mixing이 줄어서가 아니라 **재구성이
줄어들어 상대적으로 커진 것**이다. 디코더 가중치에 대한 그래디언트 노름을 직접 측정하면:

```
재구성 항 1.93e+00,  mixing 항(원값) 3.98e-01
→ λ=1e-3 적용 시 그래디언트 비 = 0.0002   (사실상 영향 없음)
```

**주의**: "BCE→MSE 전환으로 스케일 균형이 깨졌다"는 설명은 정확하지 않다. BCE는 연속 목표에
대해 0으로 수렴하지 않고 바닥값이 남아 절대 크기가 부풀려지므로, 두 손실의 값끼리 비교해서는
결론을 낼 수 없다. 신뢰할 근거는 **mixing 원값이 8.3%밖에 줄지 않았다는 사실**과
**그래디언트 비 0.0002**다.

λ 후보 (수렴 시점 recon 0.0297, mixing 원값 3.282 기준):

| λ | λ×mixing | recon 대비 |
|---|---|---|
| 1e-3 (초기값) | 0.0033 | 0.11배 |
| **1e-2 (1차 시도)** | 0.0328 | **1.11배** |
| 1e-1 (2차 후보) | 0.3282 | 11.06배 |

선행 후속 논문(PPG, Comput Biol Med)은 `sep_lr = 0.05`를 썼다 — 저자들도 1e-3에서 50배를
올렸다는 뜻이므로 상향 방향은 선행과 어긋나지 않는다.

## 18. ★판정 기준 선등록 (사후 변경 금지)

**등록 시점: λ=1e-2 파일럿 실행 전. 결과를 보기 전에 기록한다.**

> **기준**: λ = 1e-2 와 1e-1 **두 조건 모두에서 bw와 ma의 최고 인코더가 동일**하면,
> 이를 튜닝 실패가 아니라 **연구 결과로 확정**한다. 그리고 판별 단위를
> **심장 vs 잡음군(+세부 유형은 가능한 범위)** 으로 조정하는 설계 변경을 검토한다.

이 기준을 미리 박아두는 이유는, 결과를 본 뒤에 "조금만 더 튜닝하면 되지 않을까"로
기준을 옮기는 것을 막기 위해서다. λ를 계속 올리며 원하는 그림이 나올 때까지 반복하면
그것은 검증이 아니라 선택 편향이다.

**현재까지의 근거 (λ = 1e-3, 에폭 63)**

```
        clean     bw     ma     em
enc0    0.435  0.041  0.036  0.038   ← 심장 성분 전담 (§7 판정: 신호 인코더, 격차 0.394)
enc2    0.108  0.422  0.373  0.219   ← bw와 ma가 같은 인코더에서 1·2위
enc5    0.122  0.284  0.235  0.231
bw/ma/em 최고 인코더 = (2, 2, 5)
```

§7 규칙(δ=0.1)을 적용하면 **enc0만 신호 인코더로 판정되고 나머지 7개는 전부 혼재**다.
Gate G1의 1번 조건(bw·ma·em 각각에 잡음 인코더 1개 이상)을 충족하지 못한다.
다만 **심장 vs 비심장 분리는 명확히 성립**한다 — enc0의 clean 상관 0.435 대 잡음 상관
0.036–0.041로, 잡음과 거의 무상관이다 (`logs/K8_seed42/plots/ep060.png`).
