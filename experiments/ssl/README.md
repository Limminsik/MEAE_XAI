# 자기지도(SSL) 본 노선 — K 최종 비교

**이것이 본 노선이다.** 잡음 지도(`experiments/supervised_noise/`)는 방향 탐색이었고
중단됐다 (D50). 여기서 K를 확정하면 모델 탐색이 끝난다.

## 무엇을 하는가

자기지도로 학습한 K ∈ {4, 8, 16} × 시드 {42, 202, 2026} 아홉 모델을 비교해
**최종 모델 하나를 고른다.** hidden 64, 나머지 설정 전부 현행 동결.

## 선정 규칙 (D52 — 결과 확인 **전**에 등록)

순서대로 적용한다. 앞 단계에서 갈리면 뒤는 보지 않는다.

| 순위 | 기준 | 무엇을 묻는가 |
|---|---|---|
| ① | **4분할 성공** — clean·bw·ma·em에 각각 **다른** 인코더가 1위인가 | 판별이 성립하는가 |
| ② | **재구성 충실도** — 15–40 Hz 보존율 최상 | 성분을 해석할 수 있는가 |
| ③ | **clean 배타성** — 설명 몫 − 잡음 누출 최대 | 마스킹이 통하는가 |

## 실행

```bash
python -m experiments.ssl.k_compare              # K 비교 + 최종 모델 선정
```

K=16은 `./run_k16.sh`로 먼저 학습한다. K=4·8은 기존 결과를 재사용한다.

## 산출물

```
experiments/ssl/outputs/
  k_compare.csv        아홉 모델 × (4분할 · clean 3종 · 재구성 2종)
  selected.json        선정된 모델과 선정 경로
  figures/
    components_<run>.png   대표 사례 성분 파형 (입력·재구성·K개 성분·참조 4종)
```

학습 산출물은 `_work/runs/K<k>_seed<seed>/`에 있다 (가중치 3개 · `history.csv` ·
`checkpoints.json`).
