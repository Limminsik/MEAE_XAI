# s4_상한_bwonly — bw 한 소스만 지도했을 때의 상한

**이 폴더는 `version5_supervised/` 의 사본이다.** 본 트리는 건드리지 않는다.
확정 모델의 코드 경로를 그대로 두려고 필요한 파일만 복사해 여기서만 고쳤다.

## 묻는 것

잡음 성분의 |r| 이 0.62~0.65 에서 정체하는 것이

- **(a) 네 소스를 동시에 학습하는 경쟁 때문인가**, 아니면
- **(b) 데이터 자체의 한계인가**

를 가른다. 이걸 모르면 다음 개선 방향을 정할 수 없다.

## 설계 — 기준선과 구조·용량·데이터를 완전히 동일하게

기준선은 `experiments/02_model/s3_잔차/C16_res_w0` 이다. 그것과 **지도 항의 범위만**
다르다. K·hidden·압축률·dilation·데이터·분할·시드를 하나도 바꾸지 않는다 —
바꾸면 용량 효과가 섞여 비교가 성립하지 않는다.

```
L = (1/L)‖x̂ − x_noisy‖² + λ_sup [ (1/L)‖ŝ₂ − r_bw‖² + γ₁(1/(L−1))‖Δŝ₂ − Δr_bw‖² ]
```

enc1·3·4 에는 지도 항이 없다. 재구성에만 기여한다.

| | 기준선 `C16_res_w0` | 이 실험 `C16_bwonly_seed42` |
|---|---|---|
| 지도 대상 | enc1~4 전부 | **enc2 (bw) 만** |
| K · hidden | 4 · 64 | 4 · 64 (동일) |
| channels · dilations | [32,32,64,64] · [1,1,4,32] | 동일 |
| 압축률 · 수용영역 | 16 · 3,316표본 | 동일 |
| λ_sup · γ₁ | 1.0 · 50 | 동일 |
| 시드 · 데이터 · 분할 | 42 · 동일 | 동일 |

## 읽을 때 주의 — 두 가지가 함께 바뀐다

`L_sup` 을 **지도하는 인코더 수로 나눈다**(여기서는 1). λ_sup 이 "지도 항 하나의 비중"
이라는 뜻을 유지하기 위해서다. 그 결과 bw 항의 **실효 가중치가 전체 지도(1/4)보다
4배 커진다.**

즉 이 실험에서는 **경쟁 제거**와 **가중치 증가**가 함께 작용한다. 상한을 재는 것이
목적이므로 의도한 설계이지만, 결과를 해석할 때 둘을 분리하지 못한다는 점을 밝혀야 한다.
|r| 이 크게 오르면, 둘을 가르려면 `--supervise-only 2` 에 `λ_sup = 0.25` 를 함께 걸어
per-encoder 가중치를 기준선과 맞춘 후속 런이 필요하다.

## 주 지표와 판정선

**enc2 ↔ 참조 bw 의 |r|.** 기준선은 val 기준 **0.6496** 이다.

| 결과 | 뜻 |
|---|---|
| **≥ 0.75** | 다중 소스 동시 학습이 병목. 잠재 공간 설계나 학습 전략에 여지 있음 |
| **0.65~0.70** | 데이터 한계. bw 를 x_noisy 에서 뽑아낼 수 있는 정보가 그 수준 |

함께 볼 것 — enc2 누출비(기준선 0.6507) · 재구성(기준선 M0 corr) ·
**지도하지 않은 enc1·3·4 가 무엇을 담았는지 4×4 |r| 행렬 전체**.

이전 SV1 실험에서 잡음 3종만 지도하고 심장을 자유롭게 뒀을 때 심장 성분이 창발하지
않았다. 이번은 반대 구성이므로 지도하지 않은 인코더들의 거동이 그 실험과 대조가 된다.

## 본 트리와 다른 곳 — 정확히 세 군데

| 파일 | 무엇 |
|---|---|
| `src/model/losses.py` | `SupervisedLoss` 에 `active` 인자, `active_encoders()` 추가 |
| `02_model.py` | `evaluate(active=)` · `train(sup_only=)` · `--supervise-only` |
| `configs/default.yaml` | `paths` 를 사본 깊이에 맞춤 (`../../../data/...`) |

**`active=None`(기본)이면 본 트리와 완전히 같은 계산이다** — 회귀 확인함.
나머지 파일은 사본 그대로다.

## 실행

```bash
cd experiments/s4_상한_bwonly
PYTHONIOENCODING=utf-8 python 02_model.py --k 4 --seed 42 \
    --supervise-only 2 --tag C16_bwonly_seed42 --out-root .
```

산출물은 `02_model/C16_bwonly_seed42/` 에 기존 형식 그대로 나온다
(`metrics/` 성분 정렬 · `restore/` 복원은 학습 종료 후 자동).
