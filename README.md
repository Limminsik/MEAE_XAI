# meae_xai — 연구 현황판

**ECG 잡음 성분 판별 및 선택적 복원.** 잡음 섞인 ECG로 다중 인코더 오토인코더(MEAE)를
자기지도 학습시킨 뒤, 어떤 인코더가 실제 잡음에 대응하는지 정량 판별하고,
그 인코더의 **인코딩만** 마스킹해 신호를 복원한다.

> **주장의 구조** ① 분해된다 → ② **판별된다**(핵심 기여) → ③ **판별이 진짜다**(마스킹 인과 검증)
> **작업의 위계** 재구성 = 모델의 목표 · 분리 = 부산물 · 판별 = 우리 기여

문서는 **이 파일**(현황·이력·산출물 지도)과 [RESEARCH_DESIGN.md](RESEARCH_DESIGN.md)(설계서) 둘뿐이다.
[CLAUDE.md](CLAUDE.md)는 작업 규칙.


## 4. 핵심 수치

### 데이터 (S1, 동결)

| | |
|---|---|
| 분절 | 46기록 × 180 = **8,280** (train 32 / val 5 / test 9 기록) |
| 주입 SNR | bw·ma·em 독립 균등추첨 **[0, 12] dB**, 실측 오차 최대 2.9e-07 dB |
| 신호 전력 | **분산 기준** — `mean(x²)`는 전극 오프셋이 중앙 35.1%를 차지 |
| 잡음 원본 | NSTDB 채널 0(noise1), 시간 70/30 분할, 1샘플당 45.9회 재사용 |
| R-피크 | 104,748개 (`f` 심볼 포함) |

### 분리 한계의 독립 근거 — 참조끼리의 상관

| 쌍 | 평균 \|r\| | 중심주파수 |
|---|---|---|
| **bw–ma** | **0.318** | bw 0.85 Hz · ma 5.49 Hz |
| bw–em | 0.221 | em 2.49 Hz |
| ma–em | 0.164 | clean 13.30 Hz |
| clean–잡음 | 0.065–0.083 | |

**bw와 ma는 정답끼리 0.32로 상관돼 있어 어떤 기법으로도 완전 분리가 불가능하다.**
같은 신체 움직임에서 동시에 발생하기 때문. em이 분리되는 것은 주파수가 아니라
**전극 접촉 변화라는 다른 물리 기전** 때문이며, 대역 필터로는 얻을 수 없는 결과다.

### 재구성 충실도 (T6.5, λ_z=1e-3)

| 실행 | 선택 에폭 | 전대역 | **15–40 Hz** | R-피크 진폭비 | 잔차–clean | 판정 |
|---|---|---|---|---|---|---|
| K8_seed42 | 88 | 0.921 | 0.579 | 0.901 | 0.200 | ✘ |
| K8_seed202 | 57 | 0.850 | 0.629 | 0.896 | 0.295 | ✘ |
| K8_seed2026 | 46 | 0.785 | 0.568 | 0.849 | 0.374 | ✘ |
| K4_seed42 | 48 | 0.814 | 0.487 | 0.825 | 0.379 | ✘ |
| K4_seed202 | 84 | 0.809 | 0.544 | 0.873 | 0.323 | ✘ |
| **K4_seed2026** | 178 | 1.069 | **0.843** | **1.015** | **0.048** | **✔** |

디노이징 지수는 6/6 통과. **못 담는 것의 정체는 잡음이 아니라 QRS 모서리**다
(잔차–clean 0.05–0.38 ≫ 잔차–잡음 0.03–0.22).

### 지표 상한 (해석 주의)

- **R-피크 F1 상한 0.981** — 검출기(neurokit2)와 사람 주석의 불일치. 마스킹 전이 0.956이라
  개선 여지가 2.5%p뿐이다. **개선의 증명에 쓸 수 없고 심박 훼손 경고등으로만 쓴다.**
- **상관의 산포는 주입 SNR로 설명된다** — 잡음 인코더–bw 중앙 \|r\|이 SNR 0–3 dB에서 0.805,
  9–12 dB에서 0.461(스피어만 −0.50). 잡음이 약하면 잡을 대상이 없는 것이지 실패가 아니다.

## 5. 결정 이력

원고 방법·고찰과 심사 답변에 그대로 인용한다. 상세 근거는 git 이력(`c9791ab` 이전) 참조.

### 데이터·모델 (S1–S2)

| # | 결정 | 근거 |
|---|---|---|
| D02 | NSTDB 잡음 **채널 0(noise1)** | `nst` 도구가 채널 번호끼리 짝지어 섞는 관례. 118e00 역산에서 동일 지연 531200에 수렴 |
| D03 | 기록 단위 **32/5/9**, 층화 없음, `split_seed 42` | 46×(0.7/0.1/0.2)이 정수로 안 떨어짐. 학습 시드와 분리 |
| D04 | 신호 전력 `mean(x²)` → **`var(x)`** | DC가 전력의 중앙 35.1%(최대 97.5%)를 차지해 명목·실제 SNR이 0–10 dB 어긋남 |
| D06 | 비트 심볼에 **`f` 추가** | 빼면 217번의 실제 심박 260개가 누락 |
| D08 | `nstdbgen` 재사용 **기각** | 잡음 1종·구간 43%·SNR 6단계 고정, 잡음 시간 분할 통제 불가 |
| D09 | MIT-BIH 자체 잡음 구간 **학습 미사용** | 전체의 1.68%뿐이고 성분별 참조가 없어 채점 불가 |
| D10 | 선행 저장소 **무수정 이식** (MIT) | `d0c94a9d`(기반) · `91f1e0e2`(후속) |
| D11 | sparse mixing = **`Alternative`** | ECG 실험 설정이 쓴 구현. PPG 논문은 다른 구현+다른 가중치로 짝이 다름 |
| D12·D13 | 입력 **3840** 대칭 제로 패딩 | 인코더 깊이 8 → 256의 배수 필요. 선행도 6000→6144. 4096은 패딩이 두 배 |
| D14 | 모든 상관·지표는 **crop 후 3600** | 패딩 0 구간이 상관을 희석. `metrics.score()`가 3840을 차단 |
| D15 | **K = {4, 8}** | K=6은 `GroupNorm(num_groups=K)`가 채널을 나누지 못해 실행 불가 |
| D16 | 재구성 **BCE → MSE** | 정규화 없음 + ECG 음수. zero-recon도 함께 MSE |

| D33 | **`lambda_z_l2` 1e-3** (선등록 처방) | 게이트 후에도 보존율 0.31–0.68로 6/6 미달. **기준 0.7 이동 없음**(0.683도 미달 처리) |

| D37 | **개선 사이클 종료 선언** | λ_z 재실행이 마지막 개선 시도. 미달이면 한계로 서술 |

| D40 | 표 1 = 인코더×참조, **\|r\| + 원값 RMSE + Wilcoxon Holm p** | 배율 보정 RMSE는 `RMS(ref)·√(1−r²)`로 \|r\|의 단조 변환임이 확인돼 제외 |
| D42 | 대표 분절 = **\|r\| 평균 백분위가 50%에 최근접** | 최고 사례를 고르는 것은 선택 편향 |
| **D47** | **D43·D44 보류** (대표 모델 = 충실도 통과 모델 중 최고, K 역할 조정) | K=4로 넘어갔던 것은 통과 모델이 K=4에만 있었던 **임시 타협**. 주 축인 K=8에서 병목을 진단한 뒤 재결정 |
| **D48** | **λ_z 병목 진단 실험** — K8 s42, `λ_z=0`, 나머지 동결. 판정 기준 3종 사전 등록 | ①보존율 개선+분리 유지 → L2 병목, 절충값 탐색 ②개선 미미 → 구조·용량으로 직행 ③보존율 개선+분리 붕괴 → **재구성–분리 상충의 실증**, 그 자체가 발견 |

### 예측이 빗나간 것 (원고 고찰용)

- **λ가 클수록 성분 간 상관이 낮아질 것으로 예상했으나 반대였다** (중앙 0.362 → 0.507 → 0.568).
  mixing 손실은 디코더 **가중치 블록**을 벌하지 성분 파형의 상관을 직접 벌하지 않는다.
  → 이 경보에 대응해 λ를 올리는 것은 근거가 없다. 경보 임계는 0.7 → **0.75**로 상향.
- **"BCE→MSE 전환으로 λ 스케일이 깨졌다"는 설명은 부정확했다.** BCE는 연속 목표에서 바닥값이
  남아 절대 크기가 부풀려지므로 손실 값끼리 비교할 수 없다. 신뢰할 근거는 mixing 원값 감소율과
  그래디언트 비였다.

## 7. 원고 반영 대기

**A. 즉시 개정** — 표 2를 기법 비교 → M0–M5 계단으로 · DAE 문단 삭제 · 아블레이션을 주 실험(그림 3)으로 ·
K {4,6,8} → {4,8} · 입력 3600 → 3840 · 학습 9회 → 6회 · F1을 개선 지표에서 경고등으로(상한 0.981 병기) ·
SNR 정의를 `nst`의 QRS 기준과 다르다고 명시

**B. 방법부 신설** — 잡음 채널 선택 근거 · 분산 기준 SNR · 분할 규칙 · 잡음 재사용률 ·
이식 범위와 라이선스 · BCE→MSE · sparse mixing 구현 선택 · **체크포인트 지표(우리 기여, 선행은 수동 검사)** · λ 상향 근거

**C. 한계** — 분절 단위 진폭 정규화의 비현실성 · 참조 신호의 1.68% 오염 · 평가셋 부정맥 비율 낮음 ·
F1 개선 여지 2.5%p · ma가 47.3%에서 증폭 주입 ·
**재구성 15–40 Hz 0.49–0.84, 6개 중 1개만 기준 충족, 주 결과는 해당 모델 기준**

**D. 판별 단위 확정 후** — 초록·서론의 "3종 판별" 전제 · 표 1 행 구성 · Gate G1 서술 · 제목의 입자도
