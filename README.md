# 지도학습 다중 인코더 오토인코더 기반 ECG 잡음 성분 분리와 디노이징

K개 인코더에 잡음원을 하나씩 배정해 지도학습하고, **추론 시점에 잡음 인코딩을 꺼서**
심전도를 복원한다. 무엇이 섞여 있었는지 성분으로 보여 주고, 그것을 제거한 뒤, 남은
신호의 품질까지 검증한다.

문서는 둘이다.
- **`README.md`** (이 문서) — 방법과 결과. Methods(데이터·모델·평가)와 지표 정의.
- **`RESEARCH_DESIGN.md`** — 확정 모델 하나로 무엇을 주장하고 그 근거를 어느 산출물이
  대는가. 원고의 Table·Figure 배치와 사전 등록 사항.

---

## 1. 문제 설정

심전도에는 세 가지 잡음이 섞인다 — 기저선 변동(bw) · 근전도(ma) · 전극 운동(em).
일반 디노이저는 "깨끗해진 신호" 하나만 내놓으므로 **무엇을 얼마나 제거했는지 알 수 없고**,
그 결과를 신뢰할 근거도 신호 자체 안에 남지 않는다.

이 연구는 세 가지를 차례로 한다.

| # | 무엇을 하는가 | 어떻게 평가하는가 |
|---|---|---|
| **①** | **잡음 성분 분리** — 신호 안에 어떤 잡음이 얼마나 들어 있는지 성분으로 갈라낸다 | 주입한 참조 파형과 직접 대조 (§2.3.1) |
| **②** | **디노이징** — 인코더 마스킹으로 잡음 성분을 끄고 신호를 복원한다 | 참값 대비 복원 정확도, 고전 방법과 비교 (§2.3.2) |
| **③** | **신호 품질 평가** — 복원된 신호가 실제로 쓸 만해졌는지 본다 | 참값 없는 품질 지수와 임상 측정값 (§2.3.3·§2.3.4) |

①이 성립해야 ②의 "끄기"가 정당하고, ②가 되어야 ③에서 볼 것이 생긴다.
**③은 참값 없이도 성립하는 층**이므로, 참값이 없는 외부 데이터로 그대로 확장된다(§2.3.5).

## 2. Methods

### 2.1 데이터

MIT-BIH Arrhythmia (MLII) 에 MIT-BIH Noise Stress Test 잡음을 주입해 만든다.
**주입 성분을 개별 보존**하므로 성분을 파형 단위로 직접 채점할 수 있다 — 선행 연구가
심박수 같은 파생 지표로 간접 평가할 수밖에 없었던 부분이다.

| 항목 | 값 |
|---|---|
| 표본율 · 분절 | 360 Hz · 10초 = **L = 3,600** 표본 (비중첩) |
| 주입 | bw·ma·em **3종 상시**, 분절마다 잡음별 SNR 독립 균등추첨 0–12 dB |
| 분할 | **기록(환자) 단위** — train 32기록 5,760 · val 5기록 900 · test 9기록 1,620분절 |
| 잡음 풀 | train/val 과 test 가 서로 다른 시간 구간을 쓴다 |

```
x_noisy = x_clean + bw + ma + em          (항등으로 성립)
```

분절 하나는 `x_clean`·`x_noisy`·`bw`·`ma`·`em`·`rpeaks` 를 함께 담는다.
분할이 기록 단위이므로 같은 환자의 분절이 train 과 test 에 나뉘어 들어가지 않는다.

test 는 선정에 전혀 쓰지 않는다 — 탐색과 체크포인트 선택은 val 로만 한다.

### 2.2 모델

#### 2.2.1 구조

K개 인코더가 **같은 입력**을 각자 받고, 인코딩을 채널 축으로 이어 붙여 **단일 공유
디코더**에 넣는다.

```
z_k = E_k(x)                    k = 1…K        인코딩
x̂   = D(z_1, …, z_K)                           재구성
```

**인코더** — 블록 D개의 직렬이고 D = `len(channels)` 다. 블록 j 는 dilation d_j 를 갖는다.

```
Conv1d(k=7, dilation=d_j, padding=3·d_j) → ReLU → BatchNorm
Conv1d(k=7, dilation=d_j, padding=3·d_j) → ReLU → MaxPool1d(2) → BatchNorm
```

블록마다 MaxPool 2배가 걸리므로

```
압축률 = 2^D        인코딩 시간축 = L / 2^D        조각당 시간 = 2^D / fs
```

블록 D개 뒤에 1×1 Conv + ReLU 로 채널을 `hidden/K` 로 줄인 것이 인코딩이다.

**디코더** — 인코더와 대칭이고 블록마다 같은 dilation 을 쓴다.

```
head    Conv1d(hidden → c[−1], k=1) → ReLU → GroupNorm(num_groups=K)
블록    Upsample(2) → ConvTranspose1d(k=7, dilation=d_j, padding=3·d_j) → ReLU → GroupNorm(K)
출력    weight_norm(Conv1d(c[0] → 1, k=1))
```

**수용영역** — 층을 빼면 줄어들므로 dilation 으로 보전한다. bw 의 느린 출렁임
(0.35 Hz, 주기 2.9초)을 보려면 그만큼이 필요하다.

```
rf ← 1,  stride ← 1
블록 j 마다:   rf ← rf + 2·(7−1)·d_j·stride + stride
               stride ← 2·stride
```

**패딩** — 입력 길이가 2^D 의 배수여야 한다. 깊이에서 유도한다.

```
padded   = ⌈L / 2^D⌉ · 2^D          (양쪽 대칭이 되도록 홀수면 2^D 한 칸 더)
pad_each = (padded − L) / 2
```

모든 지표는 중앙 3,600 을 잘라낸 뒤 계산한다 — 0 구간이 상관을 희석하기 때문이다.

**확정 설정**

| 항목 | 값 |
|---|---|
| K · 시드 · hidden | 4 · 42 · 64 |
| channels · 깊이 | **[32, 32, 64, 64]** · D = 4 |
| **압축률** | **16** — 인코딩 시간축 225, 조각당 **0.044초** |
| dilations | **[1, 1, 4, 32]** |
| 수용영역 | **3,316 표본 = 9.21초** |
| 패딩 | 불필요 (3,600 이 16의 배수) |
| 파라미터 | 95,074 |

압축률 선택의 근거는 §4.1 에 있다.

#### 2.2.2 성분 분리와 마스킹

**인코더-소스 배정** (`loss.supervise`, 순서가 곧 enc1…enc4)

| enc1 | enc2 | enc3 | enc4 |
|---|---|---|---|
| `x_clean` | `bw` | `ma` | `em` |

이 배정이 프레임워크의 기반이다 — 어느 인코더가 무엇을 담는지 정해져 있으므로
"잡음 인코더를 끈다"가 곧 "bw·ma·em 을 뺀다"가 된다.

**마스킹 대상은 인코딩이다.** 인코더 가중치는 건드리지 않고, 순전파는 K개 모두 수행한
뒤 디코더 입력 직전에 해당 인코딩만 영텐서로 바꾼다. **재학습이 없다.**

```
ŝ_k = D(0, …, z_k, …, 0)                      k번째 성분        ← ① 잡음 성분 분리
B   = D(z_1, 0, 0, 0)                          복원              ← ② 디노이징
A   = x_noisy − ŝ_bw − ŝ_ma − ŝ_em             복원 (비교선)
```

**복원은 B 를 쓴다.** A 는 원본 `x_noisy` 를 유지한 채 모델 추정치만 빼므로, 모델이
아무것도 못 뽑아도 `x_noisy` 만큼은 보장된다. 신호 전체를 디코더가 새로 그려야 하는 B 와
출발선이 같지 않다. 처리 전과 나란히 놓고 "복원이 됐는가"를 물으려면 B 다.

**마스킹은 선형이 아니다.** ReLU·GroupNorm 때문에 인코딩을 0으로 두는 것이 출력에서
선형 제한이 되지 않는다. 따라서 `Σ_k ŝ_k ≠ x̂` 이고, 그 어긋남을 추적한다(압축률 16 에서 17%).

#### 2.2.3 학습 손실

기호: ŝ_k ∈ ℝ^L 은 k번째 성분(크롭 후 L = 3,600), r_k 는 배정된 참조,
B_f = L//2+1 = 1,801 은 rfft 빈 수, σ_k 는 훈련셋에서 잰 참조의 표준편차.

```
L = (1/L)‖x̂ − x_noisy‖²  +  λ_sup · L_sup                          … 재구성 + 지도

              1   K    1  ⎡  1             2         1                2
L_sup    =   ───  Σ   ───  ⎢ ─── ‖ŝ_k − r_k‖   + γ₁ ───── ‖Δŝ_k − Δr_k‖
              K  k=1  σ_k² ⎣  L                       L−1

                                 1                  2        1                       2 ⎤
                          + γ₂  ───── ‖Δ²ŝ_k − Δ²r_k‖   + β ─── ‖ |F ŝ_k| − |F r_k| ‖   ⎥
                                 L−2                         B_f                        ⎦
```

| 연산자 | 정의 | 길이 | 구현 |
|---|---|---|---|
| Δ | x[t] − x[t−1] | L−1 = 3,599 | `torch.diff(x, n=1, dim=-1)` |
| Δ² | x[t] − 2x[t−1] + x[t−2] | L−2 = 3,598 | `torch.diff(x, n=2, dim=-1)` |
| F | 실수 FFT 크기 | B_f = 1,801 | `torch.fft.rfft(x, norm="ortho").abs()` |

| 기호 | 설정 키 | 역할 | 확정값 |
|---|---|---|---|
| λ_sup | `loss.lambda_sup` | 지도항 전체 비중 | **1.0** |
| γ₁ | `loss.gamma_sup` | 1차 차분 — 기울기 | **50** |
| γ₂ | `loss.gamma2_sup` | 2차 차분 — 곡률 | **0** |
| β | `loss.beta_sup` | \|FFT\| 크기 — 대역 분포 | **0** |
| σ_k | `loss.sup_normalize` | 소스별 정규화 | **없음** (σ_k = 1) |

**각 항이 잡는 것**

- **파형 항** — 성분이 참조와 같은 값을 갖게 한다.
- **차분 항** — 파형 일치만으로는 참조의 국소 고주파(자글자글한 변화)가 학습되지 않는다.
  그 성분은 제곱오차에 거의 기여하지 않아 평탄한 해가 이득이기 때문이다. 변화량을 맞추면
  그 대역이 손실에 잡힌다. 1차가 기울기, 2차가 곡률이다.
- **주파수 항** — 차분은 이웃 표본 차이만 보지만 이 항은 대역 분포 자체를 맞춘다.
  크기만 비교하고 위상은 보지 않는다(위상은 파형 항이 이미 본다).

**정규화 규약 세 가지**

1. **항마다 자기 길이로 나눈다** (L, L−1, L−2, B_f). 길이가 다른 항을 같은 눈금에 놓아야
   γ·β 가 상대 비중을 그대로 나타낸다.
2. **k 에 대해 합이 아니라 평균**(1/K)이다. K 를 바꿔도 λ_sup 의 뜻이 유지된다.
3. **FFT 는 `norm="ortho"`** 다. Parseval 로 `Σ|X|² = Σ|x|²` 이 성립해 빈 평균이 표본
   평균과 같은 눈금에 놓인다 — β 를 γ 와 같은 방식으로 읽을 수 있다.

**정칙화 3항은 끈다** (선행의 sparse mixing · zero reconstruction · 인코딩 L2 = 0).
"어떻게 나눌지 모를 때 돕는" 항인데, 답을 직접 주는 여기서는 불필요하고 목표와 충돌할
수 있다.

**ŝ_k 를 얻는 경로**는 `model.component(x, k)` — 평가의 마스킹 복원과 **같은 경로**다.
학습과 평가가 같은 길을 지나게 하려는 것이다.

#### 2.2.4 체크포인트 선택

답을 직접 주므로 대리 지표가 필요 없다. **성분 정렬 손실 자체**로 고른다.

```
C  = { t : L_sup^val(t) ≤ ratio · min_τ L_sup^val(τ) },   ratio = 1.5      후보
t* = argmin_{t ∈ C} L_sup^val(t)                                            선택
```

- `L_sup^val` 은 학습 손실과 **같은 정의**다 (차분·주파수·σ 정규화 포함, k 평균).
- val 앞 300분절에서 **2에폭 간격** 산출. 그 에폭만 후보 가중치로 남는다.
- **조기 종료도 같은 양** — `val_sup` 이 **50에폭** 정체하면 멈춘다. 최대 300에폭.
- 민감도로 ratio {1.2, 1.5, 2.0} 을 함께 싣는다.

### 2.3 평가

문제 설정의 세 축을 그대로 따라간다. 뒤로 갈수록 응용에 가깝고, **참값 의존도가 달라진다.**

| 절 | 무엇을 평가 | 참조 | 비교 대상 |
|---|---|---|---|
| 2.3.1 | ① 잡음 성분 분리 | 참조 4종 | 성분 × 참조 (4×4) |
| 2.3.2 | ② 디노이징 | `x_clean` | `x_noisy` vs B (+ 고전 3종) |
| 2.3.3 | ③ 신호 품질 | **없음** | `x_noisy` vs B |
| 2.3.4 | ③ 임상 측정값 | `x_clean` | `x_noisy` vs B |
| 2.3.5 | 외부 일반화 | **없음** | 입력 vs B (+ 고전 3종) |

**2.3.2 와 2.3.3 이 서로를 보완한다.** 전자는 표준 지표라 문헌 비교가 되고, 후자는 참값
의존을 우회해 독립적 근거를 준다 — MIT-BIH 원본도 완전한 참값이 아니라는 한계에 대한
대비이면서, 참값이 없는 외부 데이터로 넘어가는 다리이기도 하다.

---

#### 2.3.1 잡음 성분 분리 평가

성분 ŝ_k 가 배정된 참조 r_j 를 얼마나 정확히 담아냈는지 본다. 배정이 사전에 정해져 있으므로
**대각이 주 지표**이고 비대각은 누출 확인용이다. 4×4 행렬로 낸다.

**전처리** — 성분과 참조를 각각 **분절 내 z-표준화**한다. 성분의 절대 진폭은 비선형
디코더의 임의 출력이고 참조 4종의 RMS 도 서로 다르므로(clean 0.204, 잡음 0.113~0.119 mV),
표준화하지 않으면 크기 차이가 값을 지배한다.

```
x̃ = (x − mean(x)) / std(x)          분절 안에서만 계산한다
```

분절마다 지표를 구한 뒤 **분절 간 평균 ± SD**(ddof=1)로 집계한다. 분절을 이어붙여 일괄
계산하지 않는다 — 분절마다 다른 잡음이 주입되었고 진폭 큰 분절이 결과를 지배하기 때문이다.

---

**① \|r\| — 전대역 파형 대응**

*개념* — 성분과 참조가 같은 모양으로 움직이는가. 가장 기본이 되는 지표다.

$$|r|_{kj} = \frac{1}{S}\sum_{s=1}^{S}\bigl|\rho(\tilde{s}_k^{(s)},\ \tilde{r}_j^{(s)})\bigr|$$

*보는 법* — 높을수록 좋다. 대각이 크고 비대각이 작으면 분리가 된 것이다.

*절댓값을 쓰는 이유* — 인코딩과 디코더 가중치가 동시에 부호 반전돼도 재구성이 불변이라
성분이 참조와 **반대 위상**으로 수렴할 수 있다. 부호 반전은 무관이 아니라 반대 위상의
일치다. 원 부호의 분포는 양수 비율로 따로 기록한다.

---

**② RMSE_norm — 표준화 척도의 거리**

*개념* — 모양만이 아니라 **값 자체**가 얼마나 어긋나는가. \|r\| 과 상보적이다.

$$\text{RMSE}_{\text{norm},\,kj} = \sqrt{\frac{1}{L}\sum_{i=1}^{L}\bigl(\tilde{s}_k[i] - \tilde{r}_j[i]\bigr)^2}$$

*보는 법* — 낮을수록 좋다. 부호 정렬을 하지 않으므로 반대 위상이면 값이 커진다 —
\|r\| 이 높은데 RMSE_norm 도 크면 위상이 뒤집혔다는 신호다.

---

**③ MAD — 최악 지점**

*개념* — 평균적으로는 맞아도 **특정 구간에서 크게 어긋나는** 경우를 잡는다.

$$\text{MAD}_{kj} = \max_i \bigl|\tilde{s}_k[i] - \tilde{r}_j[i]\bigr|$$

*보는 법* — 낮을수록 좋다. 단위는 표준편차다. 참조 파형의 첨도에 영향받으므로 열 안에서
비교한다(같은 참조끼리).

---

**④ F1 — 박동 구조의 존재**

*개념* — 파형이 얼마나 닮았는지와 별개로, **박동 정보가 담겼는지**만 본다. 심장 성분
검증에 쓰이며, 잡음 성분에서는 낮게 나오는 것이 정상이다.

성분에서 R-피크를 검출해 참조 피크와 1:1 매칭한다. 허용오차 50 ms, 참조 피크가 3개 미만인
분절은 제외한다. 검출 전에 성분의 부호를 참조에 맞춘다(`sign_align`) — R파가 아래로 향하면
검출기가 T파나 S파를 집어 F1 이 실제보다 낮게 나오기 때문이다.

$$\text{precision}=\frac{TP}{TP+FP},\quad \text{recall}=\frac{TP}{TP+FN},\quad
F_1=\frac{2\cdot\text{precision}\cdot\text{recall}}{\text{precision}+\text{recall}}$$

*보는 법* — 심장 성분에서 높아야 한다. \|r\| 하나로는 "심장이 없다"(F1 낮음)와
"박동은 있는데 형태가 덜 맞는다"(F1 높고 r_QRS 낮음)가 구분되지 않는다.

---

**보조 ⑤ 누출비 — 자기 소스에만 집중했는가**

*개념* — 성분이 배정된 참조 말고 다른 참조를 얼마나 담고 있는가.

$$\text{누출비}_k = \frac{\max_{j \neq b(k)} |r|_{kj}}{|r|_{k,\,b(k)}}$$

`b(k)` 는 인코더 k 에 배정된 참조다. 분자는 비대각 최대, 분모는 대각.

*보는 법* — **낮을수록 좋다.** 1 을 넘으면 배정된 소스보다 다른 소스를 더 담았다는 뜻이다.

---

**보조 ⑥ 대역 에너지 — 어느 주파수 대역을 점유했는가**

*개념* — 성분이 물리적으로 타당한 대역에 있는지 본다. 방향성 지표가 아니라 **진단 도구**다.

Welch PSD(nperseg 1024, hann, 50% 겹침)의 대역별 전력 비율. 분모는 0.05–40 Hz.

$$\text{ratio}_b = \frac{\sum_{f \in b} P(f)}{\sum_{f \in [0.05,\,40)} P(f)}$$

| 대역 | 범위 | 무엇이 여기 있나 |
|---|---|---|
| vlf | 0.05–0.5 Hz | 기저선 변동 |
| lf | 0.5–5 Hz | T파·P파, 전극 운동 |
| qrs | 5–15 Hz | QRS 복합체 |
| hf | 15–40 Hz | 근전도 |

*보는 법* — 참조의 대역 분포(bw vlf 0.800 / em lf 0.699 / ma vlf 0.472 + hf 0.159)와
대조한다. 성분이 같은 대역을 점유하면 물리적으로 타당한 것이다.

---

**보조 ⑦ r_QRS — 심장 파형의 형태 충실도**

*개념* — 전대역 \|r\| 은 저주파 혼입에 희석된다. QRS 대역만 남기고 다시 재면 **형태**가
맞는지가 분리되어 보인다.

5–15 Hz Butterworth(4차, filtfilt 영위상) 통과 후 \|r\| 을 같은 방식으로 계산한다.
영위상이 필수다 — 위상 지연이 남으면 상관이 그만큼 떨어져 파형 충실도와 섞인다.

*보는 법* — 높을수록 좋다. 잡음 성분에서는 뜻이 없으므로 **clean 행에만** 싣는다.

---

**하지 않는 것** — 표본 수(N = 3,600) 기반 p값(시간적 자기상관으로 독립 관측 가정
불성립) · 순열 검정 · 코히런스 · 인코더에 참조 이름 붙이기(배정으로 이미 정해져 있다).

---

#### 2.3.2 디노이징 평가

복원 신호가 `x_noisy` 보다 `x_clean` 에 가까워졌는가. **mV 원단위**로 재고 표준화하지
않는다 — 여기서는 절대 크기가 의미를 갖기 때문이다.

**비교 대상 7종**

| 기호 | 정의 | 역할 |
|---|---|---|
| **B** | `D(z₁, 0, 0, 0)` | **주 결과** |
| ⓐ | `x_noisy` | **기준선** — ΔSNR 의 기준점 |
| 대역통과 0.5–40 Hz | Butterworth 4차 + filtfilt, 입력 평균 복원 | 비교 (고전) |
| 웨이블릿 임계값 | sym8 level 5, universal threshold 소프트 | 비교 (고전) |
| 웨이블릿+기저선제거 | sym8 level 7, 근사계수 제거 + 임계값 | 비교 (고전) |
| A | `x_noisy − ŝ_bw − ŝ_ma − ŝ_em` | 보조 (성분 추정 검증) |
| ⓑ | M0 = `D(z₁,z₂,z₃,z₄)` | 참고 |

ⓐ·ⓑ 를 두는 이유: 개선량 중 어디까지가 재구성 자체의 몫이고 어디부터가 마스킹의
몫인지 갈라야 한다.

> **고전 비교선 두 가지 주의**
>
> 1. **DC 오프셋을 되돌린다.** 0.5 Hz 고역통과와 근사계수 제거는 `x_clean` 이 가진 기저
>    오프셋(중앙값 −0.283 mV)까지 지운다. 그대로 두면 상수 오차가 얹혀 불공정하다.
>    **입력의 평균**을 되돌린다 — 참값을 쓰지 않으므로 누수가 없다.
> 2. **웨이블릿 임계값 단독은 bw 를 못 없앤다.** 임계값이 세부계수(고주파)만 건드리는데
>    기저선 변동은 근사계수에 있다. 근사계수를 함께 버린 변형을 따로 싣는다.

---

**주 지표 ① SNR · ΔSNR — 잡음이 얼마나 줄었는가**

*개념* — 신호 전력 대비 잔여 오차 전력. 디노이징 문헌의 표준 지표다.

$$\text{SNR}(\hat{x}) = 10\log_{10}\frac{\mathrm{var}(x_{\text{clean}})}
{\frac{1}{L}\sum_i \bigl(x_{\text{clean}}[i] - \hat{x}[i]\bigr)^2}\quad[\text{dB}]$$

$$\Delta\text{SNR} = \text{SNR}(\hat{x}) - \text{SNR}(x_{\text{noisy}})$$

*보는 법* — 높을수록 좋다. **ΔSNR 이 곧 처리 전 대비 개선량**이다. 정의상 `x_noisy` 가
기준선이고, `x_clean` 은 두 SNR 을 계산하기 위해 필요하다.

---

**주 지표 ② PRD — 잔여 왜곡 비율**

*개념* — 원 신호 크기 대비 오차의 상대 크기. 백분율이라 데이터셋 간 비교가 쉽다.

$$\text{PRD} = 100 \times \sqrt{\frac{\sum_i \bigl(x_{\text{clean}}[i] - \hat{x}[i]\bigr)^2}
{\sum_i x_{\text{clean}}[i]^2}}\quad[\%]$$

분모에서 평균을 빼지 않는다.

*보는 법* — 낮을수록 좋다. 통상 10% 미만이면 왜곡이 미미한 것으로 본다.

---

**보조 5종** (문헌 관행상 함께 보고)

| 지표 | 수식 | 방향 |
|---|---|---|
| \|r\| | 평균 제거 후 Pearson 절댓값 | 높을수록 |
| RMSE | $\sqrt{\frac{1}{L}\sum_i (x_{\text{clean}} - \hat{x})^2}$ | 낮을수록 |
| SSD | $\sum_i (x_{\text{clean}} - \hat{x})^2$ | 낮을수록 |
| MAD | $\max_i \lvert x_{\text{clean}}[i] - \hat{x}[i]\rvert$ (mV 원단위) | 낮을수록 |
| CosSim | $\dfrac{\langle x_{\text{clean}},\ \hat{x}\rangle}{\lVert x_{\text{clean}}\rVert\,\lVert \hat{x}\rVert}$ (평균 안 뺌) | 높을수록 |

> **MAD 는 §2.3.1 과 이름이 같지만 다른 값이다** — 여기는 mV 원단위, 거기는 표준화 후
> 표준편차 단위다.

---

**분해 — 언제 유효한가**

입력 SNR 구간별·기록별로 같은 지표를 다시 집계한다. 저SNR 에서 개선 폭이 큰지, 특정
기록에서만 되는지가 여기서 나온다.

```
구간: SNR < −2 · [−2, 0) · [0, 2) · [2, 5) · [5, ∞)  dB
```

---

#### 2.3.3 신호 품질 평가 — 참값이 필요 없다

`x_noisy` 와 B 에서 **각각 독립으로** 잰다. 이 층이 `x_clean` 의존을 우회한다.
참값은 판단 기준선으로만 두고 계열로 세우지 않는다.

---

**① basSQI — 기저선 대역 비중**

*개념* — 저주파에 전력이 얼마나 쏠려 있는가. 기저선 변동이 남아 있으면 커진다.

$$\text{basSQI} = \frac{P(0\text{–}1\ \text{Hz})}{P(0\text{–}40\ \text{Hz})}$$

*보는 법* — **낮을수록 좋다.** 이 지표만 방향이 반대다. bw 가 제거되면 내려간다.

---

**② pSQI — QRS 대역 비중**

*개념* — 진단에 실제로 쓰이는 대역(QRS)에 전력이 얼마나 모여 있는가.

$$\text{pSQI} = \frac{P(5\text{–}20\ \text{Hz})}{P(0\text{–}62.5\ \text{Hz})}$$

*보는 법* — 높을수록 좋다. 잡음이 줄면 상대적으로 QRS 비중이 커진다.

---

**③ kSQI — 첨도**

*개념* — 신호 분포가 얼마나 뾰족한가. 잡음 없는 ECG 는 대부분 평탄하고 R파에서만 크게
튀므로 첨도가 높다. 잡음이 섞이면 분포가 정규분포 쪽으로 퍼져 값이 내려간다.

$$\text{kSQI} = \frac{\frac{1}{L}\sum_i (x[i] - \bar{x})^4}
{\Bigl(\frac{1}{L}\sum_i (x[i] - \bar{x})^2\Bigr)^2}$$

*보는 법* — 높을수록 좋다. 정규분포면 3, 통상 깨끗한 ECG 는 5 이상이다.

---

**④ bSQI — 두 검출기의 일치도**

*개념* — 서로 다른 알고리즘의 QRS 검출기가 같은 박동을 찾는가. 잡음이 심하면 검출기끼리
어긋난다. 검출기 하나만으로는 알 수 없는 것을 두 개의 합의로 본다.

$$\text{bSQI} = \frac{|\mathcal{R}_1 \cap \mathcal{R}_2|}{|\mathcal{R}_1 \cup \mathcal{R}_2|}$$

허용오차 150 ms 안에서 1:1 매칭한 개수가 교집합, `|R₁| + |R₂| − 교집합` 이 합집합이다.
검출기는 neurokit 과 pantompkins1985 를 쓴다.

*보는 법* — 높을수록 좋다. 다만 10초 분절에 박동이 12~13개뿐이라 값이 이산적이다 —
분별력은 있으나 해상도가 거칠다.

---

**⑤ ECGMeanCoef — 박동 형태의 일관성**

*개념* — 같은 사람의 박동은 서로 닮아야 한다. R-피크 기준으로 박동을 잘라 정렬하고
평균 템플릿을 만든 뒤, 각 박동이 그 템플릿과 얼마나 닮았는지 평균한다. 잡음이 섞이면
박동마다 모양이 흐트러져 값이 내려간다.

$$\bar{t}[i] = \frac{1}{N_b}\sum_{b=1}^{N_b} x_b[i],\qquad
\text{ECGMeanCoef} = \frac{1}{N_b}\sum_{b=1}^{N_b}\rho\bigl(x_b,\ \bar{t}\bigr)$$

박동 창은 R 기준 [−200, +400] ms 이고, 박동이 3개 미만이면 NaN 이다.

*보는 법* — 높을수록 좋다. 1 에 가까우면 박동 모양이 일관된다.

---

#### 2.3.4 임상 측정값 평가

파형이 닮았다는 것과 **진단값이 맞는다**는 것은 다르다. 임상에서 실제로 재는 값이
참값에 얼마나 가까운지 본다.

**기준점을 공유한다 — 핵심 설계.** R-피크는 `x_clean` 에서 한 번 검출해 세 신호
(`x_clean` · `x_noisy` · B)에 똑같이 적용한다. 신호마다 따로 검출하면 "박동을 찾았는가"
(검출 오차)와 "찾은 자리에서 잰 값이 맞는가"(측정 오차)가 섞인다. 기준점을 고정하면
박동이 1:1 로 짝지어져 **박동별 오차**를 낼 수 있고, 남는 차이는 온전히 파형 왜곡에서
온다. 검출 성능 자체는 §2.3.1 의 F1 이 담당한다.
분절 가장자리 400 ms 안쪽 박동은 측정 창이 잘려 뺀다.

**공통 기준**

$$\text{기저선} = \frac{1}{n}\sum x[R-80\text{ms} : R-40\text{ms}]
\qquad \text{J점} = R + 40\text{ms}$$

기저선은 PR 구간(등전위선)이다. J점은 QRS 종료점을 근사한 것으로, 종료점 검출 자체가
잡음에서 특히 불안정하기 때문에 고정 오프셋을 쓴다.

---

**① ST60 · ST80 — ST 분절 편위**

*개념* — J점에서 60 ms, 80 ms 뒤의 신호 높이를 기저선 대비로 잰 값. 위로 올라가면
ST 상승, 아래로 내려가면 ST 하강이라 부르고 **심근경색과 허혈 진단의 핵심 지표**다.

$$\text{ST60} = x[J+60\text{ms}] - \text{기저선},\qquad
\text{ST80} = x[J+80\text{ms}] - \text{기저선}\quad[\text{mV}]$$

*왜 여기서 보나* — 기저선 대비로 재므로 **기저선이 흔들리면 그대로 틀린다.**
bw 가 정확히 그 기저선을 흔든다. 이 프레임워크가 가장 직접적으로 겨냥하는 지표다.

---

**② R진폭 · QRS면적 — QRS 복합체의 크기**

*개념* — R파의 높이와 QRS 복합체 아래 면적. 둘 다 **심실 비대 판정** 등에 쓰인다.
계산이 단순하고 진폭이 곧 지표라 잡음이 그대로 오차가 된다.

$$\text{R진폭} = \max\bigl(x[R\pm50\text{ms}]\bigr) - \text{기저선}\quad[\text{mV}]$$

$$\text{QRS면적} = \frac{1000}{f_s}\sum_{i=R-50\text{ms}}^{R+60\text{ms}}
\bigl|x[i] - \text{기저선}\bigr|\quad[\text{mV}\cdot\text{ms}]$$

*주의* — 둘 다 **차분 측정**이다. 기저선과 R피크가 100 ms 밖에 떨어져 있지 않아
느린 잡음은 빼면 상쇄된다(§3.4 결과 참조). 원래 잡음에 둔감한 지표다.

---

> **QT·QTc 는 제외한다.** Q파 시작부터 T파 끝까지의 시간으로 부정맥 위험을 보는 지표지만,
> 상용 ECG 판독 프로그램 간 QT 측정 차이가 6–10 ms 인데 우리 절대오차는 47–64 ms 였다.
> **지표 자체의 판별력이 없다** — T 종료점 검출이 참값에서도 흔들리기 때문이다.

---

**읽는 법** — 표와 그림의 값은 모두 **오차**다. 작아졌으면 참값에 더 가까워진 것이다.

```
x_clean 에서 잰 ST60 = 0.05 mV   (참값)
x_noisy 에서 잰 ST60 = 0.18 mV   → 오차 |0.18 − 0.05| = 0.13 mV
B 재구성에서 잰 ST60  = 0.11 mV   → 오차 |0.11 − 0.05| = 0.06 mV
```

지표마다 다음을 낸다 — 참값 중앙값 · 처리 전/후 **편향**(부호 유지) · **절대오차**
중앙/평균/p90 · **개선된 박동 비율**(박동 단위로 처리 후 절대오차 < 처리 전) ·
기록별 집계 · 입력 SNR 구간별 분해.

#### 2.3.5 외부 데이터 적용

확정 체크포인트를 **재학습 없이** 외부 ECG 에 적용한다. 학습·마스킹·복원 경로를 하나도
바꾸지 않는다. 배정이 정해져 있으므로 외부에서도 B 를 그대로 만든다.

| 소스 | 신호 | 원 규격 | → 360 Hz |
|---|---|---|---|
| vitaldb | SNUADC/ECG_II | 500 Hz, mV | 18/25 정확 |
| mimic_iv | 유도 II | 249.89 Hz, mV | 36/25 (오차 0.045%) |

**참값이 없으므로 §2.3.2 와 §2.3.4 의 오차는 낼 수 없다.** 대신 **참값이 필요 없는 층은
그대로 낸다** — 그 층은 test 에서 참값과 대조해 검증했으므로 외부에서도 같은 뜻으로 읽는다.

| 낼 수 있는 것 | 무엇 |
|---|---|
| SQI 5종 | §2.3.3 과 같은 정의. 고전 3종도 같은 표에 넣어 비교 |
| 임상 형태 지표의 **값** | §2.3.4 와 같은 측정 창. 오차가 아니라 값이다 |
| 성분 대응 | 성분 K개 ↔ (입력, M0, B) 의 \|r\|·RMSE_norm·MAD |
| 스펙트럼 특성 | 성분별 중심주파수와 대역 전력비 |

R-피크 기준점은 참값이 없으므로 **입력에서** 검출해 전 계열에 공유한다.

**분절 선정은 사전 규칙**이다 — 지표를 보지 않는다. 기록 앞 10분 · NaN · 평탄비 > 0.05 ·
포화비 > 0.005 · R-피크 < 5 · 심박수 30–200 bpm 밖 · RR 변동계수 > 0.5 를 버리고,
남은 것 중 각 기록 앞에서부터 순서대로 취한다.

**진폭 정합** — 모델은 mV 원값을 그대로 받도록 학습됐고 정규화 단계가 없다. 그 전제는
MIT-BIH 안에서만 성립하므로 분절마다 상수배해 학습 입력 SD 중앙값(0.4707 mV)에 맞춘다.

> NSTDB 잡음 조각을 참조로 붙이는 방식은 쓰지 않는다. 외부 데이터에 실제로 섞인 잡음과
> 무관한 파형이라 상관값이 "대역이 비슷하다"만 반영하고 파형 일치를 뜻하지 않는다.
> **정량 성능은 주장하지 않는다.**

### 4.4 잔차 연결 — 구현했으나 채택하지 않았다

얕은 층 출력을 디코더로 직접 전달하면 세부가 살아날 것으로 보고, **인코더별로 분리된**
잔차 경로를 구현했다. 성분 k 를 뽑을 때 인코더 k 의 잔차만 살리고 나머지는 0 이다.

**마스킹 차단 단위 검증 (통과)**

| 검증 | 결과 |
|---|---|
| 인코딩·잔차를 모두 0으로 두면 출력이 입력에 의존하지 않는가 | 서로 다른 입력의 출력 차이 **0.000e+00** |
| 성분1 이 인코더2 의 잔차를 끄는가 | 인코더2 잔차를 **100배** 흔들어도 변화 **0.000e+00** |

**성능은 올랐다** — B corr 0.909 → 0.920, SSD 57.6 → 41.7, ΔSNR +6.21 → +7.09 dB.

**그러나 감시 지표가 채택을 막았다.** 성분1 을 두 경로로 나눠 보면:

| 잔차 가중치 | 성분1 (인코딩+잔차) | **인코딩만** | **잔차만** |
|---|---|---|---|
| 0 | 0.929 | **0.929** | 0.064 |
| 0.1 | 0.934 | **0.063** | 0.709 |
| 1.0 | 0.936 | **0.068** | 0.781 |

잔차를 켜면 성분1 의 R파를 **인코딩이 아니라 잔차가 만든다.** 잡음 3종은 잔차를 꺼도
\|r\| 이 거의 그대로다(bw 0.649 → 0.647) — 심장에서만 무너진다.
"인코더가 성분을 분리한다"는 전제가 심장에 대해 성립하지 않으므로 채택하지 않았다.

가중치를 0.1 → 1.0 으로 10배 올려도 의존도가 그대로인 이유도 확인했다 — 주입 지점
**바로 다음 블록에 GroupNorm** 이 있어 더해 준 절대 크기가 지워진다(주입 크기 자체는
활성 대비 0.079 → 0.221 → 0.564 로 비례한다).

### 4.5 구현 메모 — 선행 코드 수정 지점

구조는 선행 다중 인코더 오토인코더(Webster et al.)를 이식해 쓴다. 두 곳을 확장했고,
**기본값이면 원본과 완전히 같다** (회귀 검증 최대 절대차 0.000e+00).

| # | 무엇 | 왜 |
|---|---|---|
| ① | `EncoderBlock`·`DecoderBlock` 에 `dilation` (기본 1) | 층을 줄일 때 수용영역 보전 (§4.2) |
| ② | 인코더별 잔차 연결 `skip_levels`·`skip_weight` (기본 없음/0) | 얕은 층 세부 전달 실험 — **미채택**(§4.4) |

깊이는 `channels` 길이로 정해지므로 원본 코드가 이미 지원한다.

## 6. 알려진 사항

**마스킹은 선형이 아니다.** `Σ_k ŝ_k ≠ x̂` 이고 압축률 16 에서 17% 어긋난다.
"성분들을 합치면 원본"이라는 전제가 이 구조에서 성립하지 않으므로 그 어긋남을 추적한다.
A(성분차감) 방식의 근거도 여기서 흔들린다.

**M0 재구성과 x_clean 의 상관이 낮은 것은 정상이다.** M0 는 `x_noisy` 를 재구성하도록
학습되므로 잡음을 담고 있다. 재구성 품질의 지표는 `재구성 ↔ x_noisy` 하나다.

**임상 지표는 성격이 갈린다.** ST60·ST80 은 처리 전보다 확실히 낫고(개선 박동 비율
0.62~0.67), R진폭·QRS면적 은 못하다(0.38~0.39). 후자는 차분 측정이라 잡음이 상쇄되어
**원래 잡음에 둔감한 지표**다(§3.4) — 얻을 것이 적은 자리에 재구성 오차만 얹힌다.

**잡음 3종의 성분 정렬은 0.62~0.65 에 머문다.** 심장(0.881)과 격차가 크고, 잡음끼리
서로 누출이 0.46~0.67 로 남는다.

**bSQI 는 해상도가 거칠다.** 10초 분절에 박동이 12~13개뿐이라 값이 이산적이다.

## 7. 실행

```bash
# 0) 스팟체크 그림
python 01_build.py --spotcheck

# 1) 탐색 — 기본 출력은 experiments/
python 02_model.py --k 4 --seed 42 --gamma 50 \
    --channels 32,32,64,64 --dilations 1,1,4,32 --group s1_해상도 --tag C16

# 2) 확정 모델 학습 — results/ 로 (config 기본값이 곧 확정 설정이다)
python 02_model.py --k 4 --seed 42 --tag C16_seed42 --out-root results

# 3~7) 확정 모델로 (03~06 은 test, 07 은 외부)
python 03_bss.py --run C16_seed42 --split test --final
python 04_masked_denoising.py --run C16_seed42 --split test --three-ways
python 05_figure.py --run C16_seed42 --split test
python 06_ablation.py --run C16_seed42 --split test
python 07_validation.py --run C16_seed42 --source vitaldb
```

주요 오버라이드: `--channels` · `--dilations` · `--hidden` · `--gamma` · `--gamma2` ·
`--beta` · `--sup-normalize` · `--skip-levels` · `--skip-weight` · `--group` · `--out-root`.

학습이 끝나면 성분 정렬 지표와 복원이 **항상 함께** 산출된다 (`--no-eval` 로만 끈다).

한글 콘솔 출력이 있으므로 `PYTHONIOENCODING=utf-8` 로 실행한다.
환경은 이 폴더 자체의 uv 환경이다 (Python 3.9.21, torch cu129).
단위 테스트는 `python -m pytest tests/ -q` — 37개.
