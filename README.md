# 지도학습 다중 인코더 오토인코더 기반 ECG 디노이징

K개 인코더에 잡음원을 하나씩 배정해 지도학습하고, **추론 시점에 잡음 인코딩을 꺼서**
깨끗한 심전도를 복원한다. 성분 분리 → 복원 → 임상 측정값 → 외부 데이터까지 한 줄로 잇는다.

문서는 둘이다.
- **`README.md`** (이 문서) — 방법과 결과. 수식·구조·평가 규약·실험 근거.
- **`RESEARCH_DESIGN.md`** — 확정 모델 하나로 무엇을 주장하고 그 근거를 어느 산출물이
  대는가. 원고의 Table·Figure 배치와 사전 등록 사항.

---

## 1. 문제 설정

심전도에는 세 가지 잡음이 섞인다 — 기저선 변동(bw) · 근전도(ma) · 전극 운동(em).
일반 디노이저는 "깨끗한 신호"만 내놓아 **무엇을 제거했는지 알 수 없다.**

여기서는 잡음원마다 인코더를 하나씩 두고, 각 인코더가 그 잡음을 담도록 지도학습한다.
그러면 디코더에 들어가는 인코딩 중 잡음 것만 0으로 바꿔 복원할 수 있고, **어느 성분을
얼마나 뺐는지가 그대로 드러난다.** 재학습 없이 추론 시점 조작만으로 이뤄진다.

세 가지를 차례로 확인한다.

| # | 질문 | 확인 방법 |
|---|---|---|
| ① | 인코더가 배정된 잡음원을 실제로 담는가 | 성분 ↔ 주입 참조 대응 (§4.1) |
| ② | 잡음 인코딩을 끄면 신호가 복원되는가 | 복원 지표·파형 (§4.2·4.3) |
| ③ | 복원이 임상 측정값을 참값에 가깝게 하는가 | ST·QT·QRS 오차 (§4.4) |

## 2. Methods — 데이터

MIT-BIH Arrhythmia (MLII) 에 MIT-BIH Noise Stress Test 잡음을 주입해 만든다.
**주입 성분을 개별 보존**하므로 성분을 파형 단위로 직접 채점할 수 있다.

| 항목 | 값 |
|---|---|
| 표본율 · 분절 | 360 Hz · 10초 = **L = 3,600** 표본 |
| 주입 | bw·ma·em **3종 상시**, 분절마다 잡음별 SNR 독립 균등추첨 0–12 dB |
| 분할 | **기록 단위** — train 32기록 5,760 · val 5기록 900 · test 9기록 1,620분절 |
| 잡음 풀 | train/val 과 test 가 서로 다른 구간을 쓴다 |

```
x_noisy = x_clean + bw + ma + em          (항등으로 성립)
```

분절 하나는 `x_clean`·`x_noisy`·`bw`·`ma`·`em`·`rpeaks` 를 함께 담는다.
분할이 기록 단위이므로 같은 환자의 분절이 train 과 test 에 나뉘어 들어가지 않는다.

**학습셋에도 참조를 올린다** (`Segments(cfg, "train", with_refs=True)`). 지도학습이므로
필요한 조치다.

## 3. Methods — 모델

### 3.1 구조

K개 인코더가 **같은 입력**을 각자 받고, 인코딩을 채널 축으로 이어 붙여 **단일 공유
디코더**에 넣는다.

```
z_k = E_k(x)                    k = 1…K        인코딩
x̂   = D(z_1, …, z_K)                           재구성
```

**인코더** — 블록 D개의 직렬이고 D = `len(channels)` 다. 블록 j 는 dilation d_j 를 갖는다.

```
Conv1d(k=7, dilation=d_j, padding=3·d_j) → ReLU → BatchNorm
Conv1d(k=7, dilation=d_j, padding=3·d_j) → ReLU → MaxPool1d(2) → BatchNorm
```

블록마다 MaxPool 2배가 걸리므로

```
압축률 = 2^D        인코딩 시간축 = L / 2^D        조각당 시간 = 2^D / fs
```

블록 D개 뒤에 1×1 Conv + ReLU 로 채널을 `hidden/K` 로 줄인 것이 인코딩이다.

```
z_k ∈ ℝ^(hidden/K × L/2^D)
```

**디코더** — 인코더와 대칭이고 블록마다 같은 dilation 을 쓴다.

```
head    Conv1d(hidden → c[−1], k=1) → ReLU → GroupNorm(num_groups=K)
블록    Upsample(2) → ConvTranspose1d(k=7, dilation=d_j, padding=3·d_j) → ReLU → GroupNorm(K)
출력    weight_norm(Conv1d(c[0] → 1, k=1))
```

인코더 블록 j 와 디코더 블록 c_i = j+1 이 짝이다.

**수용영역** — 층을 빼면 줄어들므로 dilation 으로 보전한다. bw 의 느린 출렁임
(0.35 Hz, 주기 2.9초)을 보려면 그만큼이 필요하다.

```
rf ← 1,  stride ← 1
블록 j 마다:   rf ← rf + 2·(7−1)·d_j·stride + stride
               stride ← 2·stride
```

**패딩** — 입력 길이가 2^D 의 배수여야 한다. 깊이에서 유도한다.

```
padded   = ⌈L / 2^D⌉ · 2^D          (양쪽 대칭이 되도록 홀수면 2^D 한 칸 더)
pad_each = (padded − L) / 2
```

모든 지표는 중앙 3,600 을 잘라낸 뒤 계산한다 — 0 구간이 상관을 희석하기 때문이다.

### 3.2 확정 설정

| 항목 | 값 |
|---|---|
| K · 시드 · hidden | 4 · 42 · 64 |
| channels · 깊이 | **[32, 32, 64, 64]** · D = 4 |
| **압축률** | **16** — 인코딩 시간축 225, 조각당 **0.044초** |
| dilations | **[1, 1, 4, 32]** |
| 수용영역 | **3,316 표본 = 9.21초** |
| 패딩 | 불필요 (3,600 이 16의 배수) |
| 파라미터 | 95,074 |

압축률 선택의 근거는 §6.1 에 있다.

### 3.3 성분과 마스킹

**마스킹 대상은 인코딩이다.** 인코더 가중치는 건드리지 않고, 순전파는 K개 모두 수행한
뒤 디코더 입력 직전에 해당 인코딩만 영텐서로 바꾼다. 재학습이 없다.

```
ŝ_k = D(0, …, z_k, …, 0)                      k번째 성분
B   = D(z_1, 0, 0, 0)                          복원 — 잡음 인코딩을 끈 재구성
A   = x_noisy − ŝ_bw − ŝ_ma − ŝ_em             복원 — 성분 차감 (비교선)
```

**인코더-소스 배정** (`loss.supervise`, 순서가 곧 enc1…enc4)

| enc1 | enc2 | enc3 | enc4 |
|---|---|---|---|
| `x_clean` | `bw` | `ma` | `em` |

이 배정이 프레임워크의 기반이다 — 어느 인코더가 무엇을 담는지 정해져 있으므로
"잡음 인코더를 끈다"가 곧 "bw·ma·em 을 뺀다"가 된다.

**복원은 B 를 쓴다.** A 는 원본 `x_noisy` 를 유지한 채 모델 추정치만 빼므로, 모델이
아무것도 못 뽑아도 `x_noisy` 만큼은 보장된다. 신호 전체를 디코더가 새로 그려야 하는 B 와
출발선이 같지 않다. 처리 전과 나란히 놓고 "복원이 됐는가"를 물으려면 B 다. A 는 표에
함께 싣되 비교선이다.

**마스킹은 선형이 아니다.** ReLU·GroupNorm 때문에 인코딩을 0으로 두는 것이 출력에서
선형 제한이 되지 않는다. 따라서 `Σ_k ŝ_k ≠ x̂` 이고, 그 어긋남을 추적 지표로 싣는다
(압축률 16 에서 17%).

### 3.4 구현 메모 — 선행 코드 수정 지점

구조는 선행 다중 인코더 오토인코더(Webster et al.)를 이식해 쓴다. 두 곳을 확장했고,
**기본값이면 원본과 완전히 같다** (회귀 검증 최대 절대차 0.000e+00).

| # | 무엇 | 왜 |
|---|---|---|
| ① | `EncoderBlock`·`DecoderBlock` 에 `dilation` (기본 1) | 층을 줄일 때 수용영역 보전 |
| ② | 인코더별 잔차 연결 `skip_levels`·`skip_weight` (기본 없음/0) | 얕은 층 세부 전달 실험 — **채택하지 않음**(§6.4) |

깊이는 `channels` 길이로 정해지므로 원본 코드가 이미 지원한다.

## 4. Methods — 손실

### 4.1 학습 손실

기호: ŝ_k ∈ ℝ^L 은 k번째 성분(크롭 후 L = 3,600), r_k 는 배정된 참조,
B_f = L//2+1 = 1,801 은 rfft 빈 수, σ_k 는 훈련셋에서 잰 참조의 표준편차.

```
L = (1/L)‖x̂ − x_noisy‖²  +  λ_sup · L_sup                          … 재구성 + 지도

              1   K    1  ⎡  1             2         1                2
L_sup    =   ───  Σ   ───  ⎢ ─── ‖ŝ_k − r_k‖   + γ₁ ───── ‖Δŝ_k − Δr_k‖
              K  k=1  σ_k² ⎣  L                       L−1

                                 1                  2        1                       2 ⎤
                          + γ₂  ───── ‖Δ²ŝ_k − Δ²r_k‖   + β ─── ‖ |F ŝ_k| − |F r_k| ‖   ⎥
                                 L−2                         B_f                        ⎦
```

| 연산자 | 정의 | 길이 | 구현 |
|---|---|---|---|
| Δ | x[t] − x[t−1] | L−1 = 3,599 | `torch.diff(x, n=1, dim=-1)` |
| Δ² | x[t] − 2x[t−1] + x[t−2] | L−2 = 3,598 | `torch.diff(x, n=2, dim=-1)` |
| F | 실수 FFT 크기 | B_f = 1,801 | `torch.fft.rfft(x, norm="ortho").abs()` |

| 기호 | 설정 키 | 역할 | 확정값 |
|---|---|---|---|
| λ_sup | `loss.lambda_sup` | 지도항 전체 비중 | **1.0** |
| γ₁ | `loss.gamma_sup` | 1차 차분 — 기울기 | **50** |
| γ₂ | `loss.gamma2_sup` | 2차 차분 — 곡률 | **0** |
| β | `loss.beta_sup` | \|FFT\| 크기 — 대역 분포 | **0** |
| σ_k | `loss.sup_normalize` | 소스별 정규화 | **없음** (σ_k = 1) |

**각 항이 잡는 것**

- **파형 항** — 성분이 참조와 같은 값을 갖게 한다.
- **차분 항** — 파형 일치만으로는 참조의 국소 고주파(자글자글한 변화)가 학습되지 않는다.
  그 성분은 제곱오차에 거의 기여하지 않아 평탄한 해가 이득이기 때문이다. 변화량을 맞추면
  그 대역이 손실에 잡힌다. 1차가 기울기, 2차가 곡률이다.
- **주파수 항** — 차분은 이웃 표본 차이만 보지만 이 항은 대역 분포 자체를 맞춘다.
  크기만 비교하고 위상은 보지 않는다(위상은 파형 항이 이미 본다).

**정규화 규약 세 가지**

1. **항마다 자기 길이로 나눈다** (L, L−1, L−2, B_f). 길이가 다른 항을 같은 눈금에 놓아야
   γ·β 가 상대 비중을 그대로 나타낸다.
2. **k 에 대해 합이 아니라 평균**(1/K)이다. K 를 바꿔도 λ_sup 의 뜻이 유지된다.
3. **FFT 는 `norm="ortho"`** 다. Parseval 로 `Σ|X|² = Σ|x|²` 이 성립해 빈 평균이 표본
   평균과 같은 눈금에 놓인다 — β 를 γ 와 같은 방식으로 읽을 수 있다.

**정칙화 3항은 끈다** (선행의 sparse mixing · zero reconstruction · 인코딩 L2 = 0).
"어떻게 나눌지 모를 때 돕는" 항인데, 답을 직접 주는 여기서는 불필요하고 목표와 충돌할
수 있다.

**ŝ_k 를 얻는 경로**는 `model.component(x, k)` — 마스킹 복원 평가와 **같은 경로**다.
학습과 평가가 같은 길을 지나게 하려는 것이다.

**소스별 정규화**(선택) — σ_k 는 훈련셋 5,760분절 전체에서 소스당 스칼라 하나로 잰다.
항 전체를 같은 σ_k² 로 나누므로 한 소스 안에서 γ·β 의 상대 비중은 설계 그대로다.
확정 모델에서는 쓰지 않는다.

### 4.2 체크포인트 선택

답을 직접 주므로 대리 지표가 필요 없다. **성분 정렬 손실 자체**로 고른다.

```
C  = { t : L_sup^val(t) ≤ ratio · min_τ L_sup^val(τ) },   ratio = 1.5      후보
t* = argmin_{t ∈ C} L_sup^val(t)                                            선택
```

- `L_sup^val` 은 학습 손실과 **같은 정의**다 (차분·주파수·σ 정규화 포함, k 평균).
- val 앞 300분절에서 **2에폭 간격** 산출. 그 에폭만 후보 가중치로 남고, 후보도 그 에폭뿐이다.
- **조기 종료도 같은 양** — `val_sup` 이 **50에폭** 정체하면 멈춘다. 최대 300에폭.
- 민감도로 ratio {1.2, 1.5, 2.0} 을 함께 싣는다.

## 5. Methods — 평가

세 층으로 본다. 뒤로 갈수록 응용에 가깝고, 참값 의존도가 달라진다.

| 단계 | 질문 | 참조 | 비교 대상 |
|---|---|---|---|
| **03** | 성분이 배정된 소스와 닮았는가 | 참조 4종 | 성분 × 참조 (4×4) |
| **04** | 복원이 `x_noisy` 보다 나아졌는가 | `x_clean` | `x_noisy` vs B (+ 고전 3종) |
| **06 ①** | 참값 없이도 품질이 올랐는가 | **없음** | `x_noisy` vs B |
| **06 ②** | 임상 측정이 정확해졌는가 | `x_clean` | `x_noisy` vs B |
| **07** | 외부 데이터에서도 같은 파이프라인이 도는가 | **없음** | 입력 vs B (+ 고전 3종) |

**04 와 06① 이 서로를 보완한다.** 04 는 표준 지표라 문헌 비교가 되고, 06① 은 참값 의존을
우회해 독립적 근거를 준다 — MIT-BIH 원본도 완전한 참값이 아니라는 한계에 대한 대비다.

### 5.1 03 — 성분 정렬

성분과 참조를 각각 **분절 내 z-표준화**한 뒤 산출 → 분절 간 평균 ± SD(ddof=1). 4×4 행렬.
배정이 정해져 있으므로 **대각이 주 지표**다.

**주 지표 4종**

| 지표 | 정의 | 방향 |
|---|---|---|
| **\|r\|** | 분절 내 Pearson 절댓값 → 분절 간 평균 | 높을수록 |
| **RMSE_norm** | `sqrt(mean((s̃_k − r̃_j)²))` | 낮을수록 |
| **MAD** | `max\|s̃_k − r̃_j\|` (단위: 표준편차) | 낮을수록 |
| **F1** | 성분의 R-피크 ↔ 참조 피크 매칭 (허용 50 ms, 참조 피크 <3 분절 제외) | 높을수록 |

절댓값을 쓰는 이유 — 인코딩과 디코더 가중치가 동시에 부호 반전돼도 재구성이 불변이라
성분이 반대 위상으로 수렴할 수 있다. 원 부호 분포는 양수 비율로 따로 기록한다.

**보조 산출**

```
누출비_k = max_{j ≠ b(k)} |r|_{kj} / |r|_{k,b(k)}          낮을수록 좋다
```

`b(k)` 는 인코더 k 에 배정된 참조다. 1 을 넘으면 배정된 소스보다 다른 소스를 더 담았다는 뜻.

**대역 에너지** — Welch PSD(nperseg 1024)의 대역별 파워 비율, 분모 0.05–40 Hz.
vlf(0.05–0.5) · lf(0.5–5) · qrs(5–15) · hf(15–40) Hz. 방향성 지표가 아니라 진단 도구다.

**r_QRS** — 5–15 Hz Butterworth(4차, filtfilt) 통과 후 \|r\|. 잡음 성분에서는 뜻이 없으므로
**clean 행에만** 싣는다.

**하지 않는 것** — 표본 수 기반 p값(시간적 자기상관) · 순열 검정 · 코히런스 ·
인코더에 참조 이름 붙이기(배정으로 이미 정해져 있다).

### 5.2 04 — 디노이징 성능

`x_clean` 기준, **mV 원단위**(표준화하지 않는다).

**주 지표 2종**

```
SNR(x̂) = 10·log₁₀( var(x_clean) / mean((x_clean − x̂)²) )        [dB]
ΔSNR   = SNR(B) − SNR(x_noisy)                                    ← x_noisy 대비 개선량

PRD    = 100 · sqrt( Σ(x_clean − x̂)² / Σ x_clean² )               [%]  분모는 평균을 빼지 않는다
```

**보조 5종** — \|r\| · RMSE · SSD · MAD(mV 원단위) · CosSim(평균 안 뺌).

**비교 대상**

| 기호 | 정의 | 역할 |
|---|---|---|
| **B** | `D(z₁, 0, 0, 0)` | **주 결과** |
| ⓐ | `x_noisy` | 기준선 |
| 대역통과 0.5–40 Hz | Butterworth 4차 + filtfilt, 입력 평균 복원 | 비교 (고전) |
| 웨이블릿 임계값 | sym8 level 5, universal threshold 소프트 | 비교 (고전) |
| 웨이블릿+기저선제거 | sym8 level 7, 근사계수 제거 + 임계값 | 비교 (고전) |
| A | `x_noisy − ŝ_bw − ŝ_ma − ŝ_em` | 보조 (성분 추정 검증) |
| ⓑ | M0 = `D(z₁,z₂,z₃,z₄)` | 참고 |

**고전 비교선 두 가지 주의**

1. **DC 오프셋을 되돌린다.** 0.5 Hz 고역통과와 근사계수 제거는 `x_clean` 이 가진 기저
   오프셋(중앙값 −0.283 mV)까지 지운다. 그대로 두면 상수 오차가 얹혀 불공정하다.
   **입력의 평균**을 되돌린다 — 참값을 쓰지 않으므로 누수가 없다.
2. **웨이블릿 임계값 단독은 bw 를 못 없앤다.** 임계값이 세부계수(고주파)만 건드리는데
   기저선 변동은 근사계수에 있다. 근사계수를 함께 버린 변형을 따로 싣는다.

**분해** — 입력 SNR 구간별·기록별로 같은 지표를 다시 집계한다(`breakdown.csv`).
"언제 유효한가"가 여기서 나온다.

### 5.4 06 ① — 신호 품질 지수 (SQI), 참값 불필요

`x_noisy` 와 B 에서 **각각 독립으로** 잰다. 이 층이 `x_clean` 의존을 우회한다.

```
basSQI = P(0–1 Hz) / P(0–40 Hz)             기저선 대역 비중.  bw 가 빠지면 낮아진다
pSQI   = P(5–20 Hz) / P(0–62.5 Hz)          QRS 대역 비중.    잡음이 줄면 높아진다
kSQI   = mean((x−x̄)⁴) / mean((x−x̄)²)²       첨도. 잡음 없는 QRS 일수록 높다 (통상 5 이상)
bSQI   = |R₁ ∩ R₂| / |R₁ ∪ R₂|              서로 다른 두 검출기의 박동 일치 (허용 150 ms)
ECGMeanCoef = mean_b corr(beat_b, 평균 템플릿)   박동 형태의 일관성
```

**ECGMeanCoef** — R-피크 기준으로 박동을 [−200, +400] ms 창으로 잘라 평균 템플릿을 만들고,
각 박동과의 상관을 평균한다. 박동이 3개 미만이면 NaN.

**bSQI 는 두 검출기**(neurokit · pantompkins1985)를 쓴다. 10초 분절에 박동이 12~13개뿐이라
값이 이산적이다 — 분별력은 있으나 해상도가 거칠다.

### 5.5 06 ② — 임상 형태 지표, 참값 기준

**기준점을 공유한다 — 핵심 설계.** R-피크는 `x_clean` 에서 한 번 검출해 세 신호
(`x_clean` · `x_noisy` · B)에 똑같이 적용한다. 신호마다 따로 검출하면 "박동을 찾았는가"
(검출 오차)와 "찾은 자리에서 잰 값이 맞는가"(측정 오차)가 섞인다. 기준점을 고정하면
박동이 1:1 로 짝지어져 **박동별 오차**를 낼 수 있다. 가장자리 400 ms 안쪽 박동은 뺀다.

```
기저선  = mean(x[R−80ms : R−40ms])                    PR 구간, 등전위선
J점     = R + 40ms                                     (QRS 종료점 검출은 잡음에 불안정)

ST60    = x[J+60ms] − 기저선          ST80 = x[J+80ms] − 기저선          [mV]
R진폭   = max(x[R±50ms]) − 기저선                                         [mV]
QRS면적 = Σ|x[R−50ms : R+60ms] − 기저선| / fs × 1000                     [mV·ms]
```

| 지표 | 임상적 의미 | 왜 여기서 보나 |
|---|---|---|
| **ST60 · ST80** | J점 이후 60·80 ms 의 기저선 대비 높이. 상승/하강이 **심근경색·허혈 진단의 핵심** | 기저선 대비로 재므로 기저선이 흔들리면 그대로 틀린다. **bw 가 정확히 그 기저선을 흔든다** |
| **R진폭 · QRS면적** | R파 높이와 QRS 면적. **심실 비대 판정** 등 | 진폭이 곧 지표라 잡음이 그대로 오차가 된다 |

> **QT·QTc 는 제외한다.** 상용 ECG 판독 프로그램 간 QT 측정 차이가 6–10 ms 인데 우리
> 절대오차는 47–64 ms 였다. **지표 자체의 판별력이 없다** — T 종료점 검출이 참값에서도
> 흔들리기 때문이다. 분할 코드는 남겨 두되 집계에서 뺀다.

**읽는 법** — 표와 그림의 값은 모두 **오차**다. 작아졌으면 참값에 더 가까워진 것이다.

```
x_clean 에서 잰 ST60 = 0.05 mV   (참값)
x_noisy 에서 잰 ST60 = 0.18 mV   → 오차 |0.18 − 0.05| = 0.13 mV
B 재구성에서 잰 ST60  = 0.11 mV   → 오차 |0.11 − 0.05| = 0.06 mV
```

`개선된_박동비율` 은 박동 단위로 처리 후 절대오차가 처리 전보다 작아진 비율이다.
부호를 살린 **편향**도 함께 싣는다. 입력 SNR 구간별·기록별 분해도 낸다.

### 5.6 07 — 외부 데이터

확정 체크포인트를 **재학습 없이** 외부 ECG 에 적용한다. 학습·마스킹·복원 경로를 하나도
바꾸지 않는다. 배정이 정해져 있으므로 외부에서도 B 를 그대로 만든다.

| 소스 | 신호 | 원 규격 | → 360 Hz |
|---|---|---|---|
| vitaldb | SNUADC/ECG_II | 500 Hz, mV | 18/25 정확 |
| mimic_iv | 유도 II | 249.89 Hz, mV | 36/25 (오차 0.045%) |
| galaxyppg | Polar H10 ECG | 130 Hz, µV | 36/13 정확 |

**참값이 없으므로 04·06② 는 못 낸다.** 대신 **참값이 필요 없는 층은 그대로 낸다** —
SQI 5종, 임상 형태 지표의 **값**(오차가 아니다), 성분 ↔ 입력/M0/B 대응, 스펙트럼 특성.
고전 비교선 3종도 같은 표에 함께 넣어 SQI 로 비교한다.

**분절 선정은 사전 규칙**이다 — 기록 앞 5분 · NaN · 평탄비 > 0.05 · 포화비 > 0.005 ·
R-피크 < 5 · 심박수 30–200 bpm 밖 · RR 변동계수 > 0.5 를 버리고 앞에서부터 취한다.

**진폭 정합** — 모델은 mV 원값을 그대로 받도록 학습됐고 정규화 단계가 없다. 분절마다
상수배해 학습 입력 SD 중앙값(0.4707 mV)에 맞춘다. 배율은 `segments.csv` 에 남는다.

R-피크 기준점은 참값이 없으므로 **입력에서** 검출해 전 계열에 공유한다.

### 6.3 γ₁ = 50 — 차분 항이 실제로 작동하는 규모

참조 자체의 에너지비가 소스마다 다르므로 같은 계수라도 걸리는 비중이 다르다
(val 300분절 중앙값, 파형항 E = mean(r²)).

| 참조 | 파형 E | Δ E | Δ² E | \|F\|² E | Δ/파형 |
|---|---|---|---|---|---|
| x_clean | 0.12827 | 0.00291 | 0.00079 | 0.19523 | 0.0136 |
| bw | 0.01469 | 0.00003 | 0.00005 | 0.01497 | **0.0019** |
| ma | 0.01390 | 0.00032 | 0.00024 | 0.01458 | **0.0218** |
| em | 0.01290 | 0.00006 | 0.00003 | 0.01293 | 0.0044 |

Δ/파형 비가 소스 간 **11.7배**까지 벌어진다. γ₁ 별 차분 항 비중:

| γ₁ | x_clean | bw | ma | em |
|---|---|---|---|---|
| 1 | 2.16 % | 0.18 % | 2.01 % | 0.43 % |
| **50** | **52.5 %** | **8.1 %** | **50.7 %** | **17.8 %** |

γ₁ = 1 에서는 어디서도 2%를 넘지 못해 차분 항이 사실상 작동하지 않는다.

**γ₂·β 를 0 으로 둔 이유** — γ₂ 는 150·300·500 에서 단조 관계가 아니었고, β 는 올릴수록
전 지표가 나빠졌다(β=10·차분 없음에서 clean \|r\| 0.101, F1 0.002 로 심장이 붕괴).
소스별 정규화는 잡음 3종을 올렸으나(em +0.086) 심장을 낮췄다(clean −0.039).

### 6.4 잔차 연결 — 구현했으나 채택하지 않았다

얕은 층 출력을 디코더로 직접 전달하면 세부가 살아날 것으로 보고, **인코더별로 분리된**
잔차 경로를 구현했다. 성분 k 를 뽑을 때 인코더 k 의 잔차만 살리고 나머지는 0 이다.

**마스킹 차단 단위 검증 (통과)**

| 검증 | 결과 |
|---|---|
| 인코딩·잔차를 모두 0으로 두면 출력이 입력에 의존하지 않는가 | 서로 다른 입력의 출력 차이 **0.000e+00** |
| 성분1 이 인코더2 의 잔차를 끄는가 | 인코더2 잔차를 **100배** 흔들어도 변화 **0.000e+00** |

**성능은 올랐다** — B corr 0.909 → 0.920, SSD 57.6 → 41.7, ΔSNR +6.21 → +7.09 dB.

**그러나 감시 지표가 채택을 막았다.** 성분1 을 두 경로로 나눠 보면:

| 잔차 가중치 | 성분1 (인코딩+잔차) | **인코딩만** | **잔차만** |
|---|---|---|---|
| 0 | 0.929 | **0.929** | 0.064 |
| 0.1 | 0.934 | **0.063** | 0.709 |
| 1.0 | 0.936 | **0.068** | 0.781 |

잔차를 켜면 성분1 의 R파를 **인코딩이 아니라 잔차가 만든다.** 잡음 3종은 잔차를 꺼도
\|r\| 이 거의 그대로다(bw 0.649 → 0.647) — 심장에서만 무너진다.
"인코더가 성분을 분리한다"는 전제가 심장에 대해 성립하지 않으므로 채택하지 않았다.

가중치를 0.1 → 1.0 으로 10배 올려도 의존도가 그대로인 이유도 확인했다 — 주입 지점
**바로 다음 블록에 GroupNorm** 이 있어 더해 준 절대 크기가 지워진다(주입 크기 자체는
활성 대비 0.079 → 0.221 → 0.564 로 비례한다). 가중치로 우회로를 통제하려던 설계가
이 구조에서는 작동하지 않는다.

## 9. 알려진 사항

**마스킹은 선형이 아니다.** `Σ_k ŝ_k ≠ x̂` 이고 압축률 16 에서 17% 어긋난다.
"성분들을 합치면 원본"이라는 전제가 이 구조에서 성립하지 않는다. A 차감 방식의 근거도
여기서 흔들리므로 그 어긋남을 추적 지표로 싣는다.

**M0 재구성과 x_clean 의 상관이 낮은 것은 정상이다.** M0 는 `x_noisy` 를 재구성하도록
학습되므로 잡음을 담고 있다. 재구성 품질의 지표는 `재구성 ↔ x_noisy` 하나다.

**임상 지표는 아직 절반이다.** ST60·ST80 만 처리 전보다 확실히 낫고(개선 박동 비율
0.65~0.70), R진폭·QRS면적·QT 는 처리 전보다 못하다(0.20~0.45).

**잡음 3종의 성분 정렬은 0.62~0.67 에 머문다.** 심장(0.909)과 격차가 크다.

## 10. 실행

```bash
# 0) 스팟체크 그림
python 01_build.py --spotcheck

# 1) 탐색 — 기본 출력은 experiments/
python 02_model.py --k 4 --seed 42 --gamma 50 \
    --channels 32,32,64,64 --dilations 1,1,4,32 --group s1_해상도 --tag C16

# 2) 확정 모델 학습 — results/ 로
python 02_model.py --k 4 --seed 42 --gamma 50 \
    --channels 32,32,64,64 --dilations 1,1,4,32 --tag C16_seed42 --out-root results

# 3~7) 확정 모델로 (03~06 은 test, 07 은 외부)
python 03_bss.py --run C16_seed42 --split test --final
python 04_masked_denoising.py --run C16_seed42 --split test --three-ways
python 05_figure.py --run C16_seed42 --split test
python 06_ablation.py --run C16_seed42 --split test
python 07_validation.py --run C16_seed42 --source vitaldb
```

주요 오버라이드: `--channels` · `--dilations` · `--hidden` · `--gamma` · `--gamma2` ·
`--beta` · `--sup-normalize` · `--skip-levels` · `--skip-weight` · `--group` · `--out-root`.

학습이 끝나면 성분 정렬 지표와 복원이 **항상 함께** 산출된다 (`--no-eval` 로만 끈다).

한글 콘솔 출력이 있으므로 `PYTHONIOENCODING=utf-8` 로 실행한다.
환경은 이 폴더 자체의 uv 환경이다 (Python 3.9.21, torch cu129).
